## 一、目標

1. **觀戰**：滑鼠為主、鍵盤為輔；鏡頭穩、好看；資訊面板齊全。試玩觀戰與經營層觀戰（天使金外框）共用同一套。
2. **商店**：版面像個商店，每件商品有數值、能比較、買得起買不起一眼看出。
3. 視野公平與引擎不動：介面只顯示觀察資料與開局規則裡有的東西。

## 二、設計

### 2.1 觀戰

- 鏡頭狀態機：`follow(pid)`、`free`、`overview`。`follow` 每幀 `cam += (target − cam) × k`，k 依速度倍率調；切換對象時同一條平滑。`overview` 由地圖尺寸一次算出中心與縮放後固定。`free` 由拖曳與滾輪改，邊界夾在地圖外一圈。
- 點選：世界座標命中半徑取模型底座；小地圖與選手列表直接帶 pid。
- 上一回合／跳回合：Worker 新增 `{ type: 'seek', round: n }`：重建同一個 `ShooterDriver`（同設定、同種子）快轉到第 n 回合凍結開始再恢復；觀戰票與試玩都走同一條。中間不送 frame。
- 面板是 DOM（天使金語彙），資料來自 `FullState`（觀戰本來就有全狀態）；擊殺訊息由連續兩幀的生死差與 `me.shots`／`tracers` 推，或協定加選用的 `kills` 事件（Worker 從回合事件取），報告說明選哪個。
- 全圖模式下保留戰術疊層；疊層的距離環改以滑鼠所在位置為圓心（可選）。

### 2.2 商店

- 重寫 `buy.ts`：資料驅動，商品清單由 `rules.weapons`／`rules.grenades`／護甲與拆彈器組成，依陣營過濾。
- 數值換算：`rpm = 60 × tps / fireTicks`；`換彈秒 = reloadTicks / tps`；`移速 % = speed / knife.speed`；精度條：`spread` 越小越滿，移動精度 `spread × movingMul`，同類別內正規化；傷害顯示「每發 × 彈丸數」與「對 100 甲的有效傷害」（用 `armorPen` 算，公式照引擎 `sim.ts` 的傷害計算，報告附公式來源）。
- 比較：卡片上每條數值與目前手上同槽位武器比，高亮優劣。
- 版面：左分類、中商品格、右選中商品的詳細數值；底部金錢列（現在、購買後）、購買倒數；熱鍵角標。

### 2.3 共用

- 游標規則沿用 1.2 包：只有對局中活著且畫布有焦點時隱藏。
- 新增的 CSS 放 `web/shooter.css` 同一套變數；不另開色系。

## 三、測試

- 單元：數值換算（rpm、秒、移速 %、精度正規化、有效傷害）；鏡頭平滑與邊界夾；跳回合後狀態雜湊與直接跑到該回合相同。
- 瀏覽器（報告附截圖）：觀戰跟隨、自由、全圖三種鏡頭各一張；點選手列表跟隨；上一回合；時間軸跳回合；擊殺訊息；商店四分類、比較高亮、買不起狀態、1366×768；經營層觀戰外框。
- 全圖零跳動的量測結果（300 幀）。

## 六、規則

- 視野公平：觀戰可以看全狀態（本來就是），試玩對局中的商店與 HUD 只能用觀察資料與開局規則。
- 配色紀律：金只給我方、選中、主要行動；對手紅；其他灰；不摻其他色系。
- 確定性：跳回合用重跑，不用快照；渲染隨機用固定雜湊。
