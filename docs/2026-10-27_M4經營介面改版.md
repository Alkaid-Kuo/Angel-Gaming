# M4 經營介面改版：戰隊基地

2026-10-27 · 待你看過。分支 `feature/m4-game-ui`（疊在 `feature/m4-management` 上，兩者都未合併 main）。

新介面在 `web/club.html`，首頁入口已改指向它。舊介面 `web/manage.html` 保留沒動，兩邊共用同一份存檔，可以互相切換比較（新版選單裡有「舊版介面」連結）。

開發時：`npm run web` 後開 <http://localhost:5173/web/club.html>。

## 一、為什麼這樣改

舊版像後台管理網頁：一排分頁、表格、純文字訊息，推進一週只跳一個文字對話框。

新版方向是「電競戰隊基地」，參考競技遊戲的客戶端（大廳、資源列、底部導覽）與收集卡牌遊戲（選手卡、稀有度框）。四個原則：

1. **基地取代分頁**：主畫面是戰隊基地，正中央是下一場比賽（雙方隊徽、VS、我方出賽名單、大按鈕「進入比賽日」），旁邊是積分榜，下面是各設施入口（戰隊、轉會市場、訓練基地、聯賽、賭盤、財務、信件），每個入口即時顯示狀態與提醒徽章。
2. **選手是卡片**：每位選手是一張收藏卡，有程序生成的頭像（戴耳機的電競選手，穿所屬戰隊的隊服）、版本稀有度框（v1 青銅、v2 白銀、v3 黃金、v4 白金、v5 鑽石、v6 傳奇）、評分、流派徽記、週薪。球探情報以「便條」蓋在卡上。
3. **重要事件都有演出**：賽季開幕、比賽日（先鋒、中堅、大將逐一揭曉，WIN／LOSE 章、比分跳動、勝利／落敗大字）、其他賽場戰果、週結算（金額滾動、名次升降、名氣變化、新報告）、賽季頒獎典禮（頒獎台）、破產。演出可以跳過或加速。
4. **數字有回饋**：現金變動時資源列的數字會滾動並飄出 ±金額；資金跑道不足時警示閃爍；積分榜有近況（勝／敗）。

三個對位改叫**先鋒、中堅、大將**（團體戰的說法），比「第 1 位」更有戰隊對決的味道。

### 沒採用的方向

記憶裡有一條「經營端可能用像素風，待討論」。像素風（例如 Kairosoft 式經營）很有遊戲感，但需要大量點陣素材，一個晚上做不完，也難保品質。所以這次選了不需要外部素材、全部程序化的方向。這次定下的畫面結構（基地、卡片、演出）之後換成像素美術仍然可以沿用。

## 二、畫面一覽

| 畫面 | 內容 |
| --- | --- |
| 標題 | 隊徽、遊戲名、繼續（顯示存檔進度）、創立新戰隊、匯入存檔 |
| 創立戰隊 | 戰隊名稱、隊徽外形（4 種）、主色（10 色）、副色（4 色）、圖騰（10 種），即時預覽；進階可指定亂數種子 |
| 基地 | 下一場比賽卡（季前是準備清單、賽季結束是結果）、積分榜、7 個設施入口＋現金卡、新聞跑馬燈 |
| 戰隊 | 三個出賽位（拖曳選手卡、或先點出賽位再點卡）、選手卡牆、空缺位連到市場 |
| 選手詳情 | 大卡、流派說明、評分／戰績／版本／週薪、戰術預設；自己的選手可升版、排訓練、解約，別人的可簽約、派球探、找他打練習賽 |
| 轉會市場 | 自由球員卡（簽約、球探）、各隊名單（依隊分組，可派球探） |
| 訓練基地 | 訓練中心（樓層亮燈＝等級、能量條＝本週剩餘場數、升級）、練習賽、戰術研發（目標用流派徽記晶片選）、本週排程、三欄報告 |
| 聯賽 | 積分榜（隊徽、近況、季後賽圈）、各週賽程與對位結果點、季後賽樹狀圖（例行賽中顯示預測） |
| 賭盤 | 每場一張注單列（主勝／客勝賠率按鈕）、右側下注單（加注晶片、上限、押中可得）、本週彩券 |
| 財務 | 大字現金、資金跑道、每週固定收支長條、資金曲線（週末現金折線＋每週淨額長條）、本賽段累計、帳本明細 |
| 信件 | 依類型分色與圖示，新信標 NEW |

導覽：桌面版左側直排導覽列，手機版改成底部導覽列；頂端資源列有隊徽、賽程進度（休、1～7、準、決的六角格）、現金、名氣、資金跑道、比賽日按鈕、選單。

## 三、視覺規格

- 色票：深靛藍底、紫與青的霓虹光、金色給錢與獎盃、紅綠表示虧賺。
- 形狀：斜切角面板、平行四邊形按鈕、六角形圖示底。
- 字型：Google Fonts 的 Noto Sans TC（標題 900 粗）與 Rajdhani（數字）；離線時退回微軟正黑體與 Bahnschrift。
- 美術全部是程式產生的內嵌 SVG，沒有外部圖檔：選手頭像（膚色、髮型、髮色、眼鏡、表情、耳機、隊服都由選手代號決定，每次一樣）、隊徽（4 種外形 × 圖騰；NPC 戰隊依隊名配色與圖騰，例如雷霆＝黃黑閃電、赤焰＝紅火焰）、8 個流派各自的徽記與顏色。

## 四、互動與存檔

- 出賽名單：桌面可拖曳；手機（觸控沒有拖曳）用「點出賽位→點卡」。選到已上場的人會互換位置。
- 解約、開新戰隊會覆蓋存檔、匯入會覆蓋存檔，都先跳確認視窗。
- 介面偏好（自選隊徽、已讀信件數、演出速度）存在另一個 localStorage 鍵 `angel-gaming-m4-ui-v1`，不進遊戲存檔；匯出的存檔不含隊徽，匯入後用預設隊徽。
- 遊戲存檔與舊版共用（`angel-gaming-m4-save-v1`）。

### 展示模式

截圖或示範用：`club.html?demo=種子&weeks=先推進幾週&to=畫面`，再加 `&match=1` 會再播一次比賽日，`&scene=第幾幕&hold=1` 停在指定那一幕。展示模式不讀也不寫 localStorage，不會覆蓋存檔，頂端會標「展示模式・不存檔」。例：`club.html?demo=7&weeks=4&match=1&scene=1&hold=1` 停在第 5 週的對戰畫面。

## 五、核心的小改動

- `src/web/manage/store.ts`：新增 `ManageGame.demo()`（不存檔的局），給展示模式用。
- `src/manage/jobs.ts`：球探與研發報告原本直接印流派代號（例如 `ambush`），改成中文名（伏擊流）。

經營核心的規則與數值沒有變。

## 六、驗證

- 型別檢查、lint、20 項單元測試、Vite 正式建置都通過（建置輸出到暫存目錄，沒有動到 LAN 站的 `dist-web`）。
- 瀏覽器實測（應用程式內建瀏覽器）：創立戰隊、簽約、球探、練習賽、研發、點選與拖曳排名單、選手詳情、下注、賽季開幕演出、比賽日演出、跳過與加速、整季推進到頒獎典禮；主控台沒有錯誤。手機寬度 375 不會橫向捲動。
- 桌面 1440×900：用 Edge 無頭模式搭配展示模式截圖檢查（基地、戰隊、市場、訓練、聯賽、賭盤、財務、對戰、他場戰果、週結算、頒獎、破產）。

沒驗到的：觸控裝置的實機操作、Safari／Firefox、Google 字型離線時的退回字型外觀。
