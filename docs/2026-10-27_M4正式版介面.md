# M4 正式版介面（天使金規格）

日期：2026-10-27　分支：`feature/m4-angel-ui`（從 `sketch/m4-full-ui` 分出）

把 `docs/2026-10-27_M4完整UI設計稿.md` 的 15 張設計稿做成真的能玩的介面，接上 `src/manage` 的遊戲核心。舊介面 `web/club.html` 保留，兩邊讀寫同一份存檔。

## 怎麼開

- 開發：`npm run dev`（或預覽伺服器 `web`）→ `http://localhost:5173/web/game.html`；首頁 `web/index.html` 的經營入口也改指到這裡。
- 打包：`vite.config.ts` 多了 `game: 'web/game.html'` 入口。
- 展示模式（不讀寫存檔，截圖與示範用）：`game.html?demo=種子`，可加
  - `weeks=N`：先推進 N 週；`to=畫面`：直接開某個畫面（hub、squad、player、market、training、league、betting、finance、inbox、title、create）
  - `match=1`：再推進一週並播比賽日演出；`scene=K`：跳到第 K 幕（超過就停在最後一幕）；`hold=1`：停在那一幕不自動往下
  - `broke`：推進完把現金改成負的（看破產畫面）；`bet`：先押一注
  - `still`：截圖模式，所有動畫直接跳到結束狀態

## 遠端試玩版

- 網址：https://claude.ai/artifact/BQAQBeayv3AdkUqEZ6dTuG （私人，要分享得從頁面的 Share 選單開）
- 進度存在開啟者自己的瀏覽器（localStorage），換裝置不會跟著走；匯出存檔在那個環境下載不了，所以選單裡不放，匯入可以用。
- 打包方式：用 vite 只打 `web/game.html`，並設 `VITE_STANDALONE=1`（隱藏首頁、舊介面、匯出三個在那邊用不了的入口），再把輸出的 HTML 去掉外層 `<html><head><body>`、資源路徑改成 `./assets/` 後發布。

## 做了哪些決定

- **配色紀律照設計稿**：金只給我方、選中、主要行動；紅只給本週對手與警示；其他隊、自由球員一律灰。比賽日演出裡改成「剛交手的那隊」標紅（演出時「本週對手」已經換成下週的了）。
- **基地不放左側導覽**：夜城的標籤就是導覽，屋頂的名單點了進戰隊；其他畫面都有導覽與比賽日按鈕。
- **對位規則的文字**：核心會把三場對位都打完、勝場多的贏，所以「先拿 2 勝」改成「三場對位，勝場多的隊伍獲勝」。
- **信件金額**：核心寫進信件的是千元（「現金 1216」），畫面上統一換成萬。
- **進場動畫只在換畫面時播**，同一畫面裡點來點去不會一直重播。

## 驗證

- `npx tsc -p tsconfig.web.json --noEmit`、`npx eslint src/web/game src/web/sketch` 通過。
- 各畫面與每一幕演出在 1920×1080 截圖檢查過版面（無溢出、無重疊）。
- 在瀏覽器實際操作：繼續存檔、簽約（資金滾動與提示）、點選換人與拖曳排陣、排練習賽與研發、下注、開幕、比賽日整套演出（三場依序揭曉、比分跳動）、信件已讀、解約確認視窗、演出速度切換、創立戰隊時的覆蓋確認。測試前備份了瀏覽器裡的舊存檔，測完已還原。
