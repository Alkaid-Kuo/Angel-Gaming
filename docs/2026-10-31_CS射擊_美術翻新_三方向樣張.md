## 一、三個方向共同的規格

**場景**：第 13 回合（下半場第一回合），7：5，我方 T 五人從地窖兩個出口推 B。自己在地窖東口朝北開火，鐵壁（CT）中彈、霜刃（CT）在 B 包點內；其餘兩名 CT 不在觀察資料裡，畫面上沒有。煙封 B 西門，手雷剛落在包點南側。

**鏡頭**：照可玩版的算法（鏡頭中心＝自己與準心的中點），比例 27 px／格，也就是縮放 1.2。目前預設縮放 1 只有 22.5 px／格，單位直徑 13 px，任何美術都救不回來；三個方向都建議把預設改成 1.2。

**地圖幾何**：全部即時讀 `MAPS.redrock()`，地圖檔沒改。

- 牆輪廓由格子描邊，再用 Douglas-Peucker（門檻 0.8 格）把格子階梯收成斜線。鋸齒只是畫面問題，碰撞不變；斜牆的畫面與碰撞最多差 0.8 格。
- 可走區永遠不會被蓋住：牆的側面帶與屋頂都裁切在牆實心內，不會超出牆格。

**視野公平**（底線，三個方向都做到）：

| 規則 | 做法 |
| --- | --- |
| 美術不透露視野外資訊 | 畫面只畫觀察資料有的東西；迷霧只改地面呈現，不拿來「遮人」，因為視野外的人根本不在資料裡 |
| 地圖常駐資訊 | 牆與地面是玩家本來就知道的，迷霧裡照樣看得到 |
| 煙擋視線 | 視線多邊形遇煙就停（與可玩版同算法），煙後方是迷霧 |
| 道具不等於掩體 | 走得到的格子上只有平鋪的東西（地板、塗裝、地上的帆布）；有高度的道具只畫在牆格或矮牆格上 |
| 敵人血量 | 不顯示，觀察資料沒有（畫面上的 27 是自己打出去的傷害） |

**隊色**：敵我色，不是陣營色。我方金、對手藍，不管這局自己是 T 或 CT；CS 老玩家熟悉的「T 黃、CT 藍」在我方打 T 時剛好一致。紅只留給危險（手雷、低血量、炸彈）。不用紅綠對撞。

**模型放大**：碰撞半徑 0.3 格在畫面上才 8 px，三個方向的單位都畫得比碰撞大（底座半徑 A 0.68 格、B 約 0.83 格、C 0.56 格）。命中判定不變；貼牆時模型會壓到牆邊，所以單位層畫在牆層之上。

## 二、方向 A 俯視戰術沙盤（主推）

把赤岩鎮當成一座擺在桌上的模型來拍：固定西北日光、一眼看得出高低。

### 調色盤

| 色碼 | 職責 |
| --- | --- |
| `#dcd2c1` `#d5cab7` `#e0d7c8` | 街道石板 |
| `#d9c3a0` | 泥地（東長廊、東巷、市集） |
| `#b78f62` `#ad8558` `#c0996c` | 地窖木地板 |
| `#e4d8c2` | 包點石板 |
| `#a2402c` | 包點塗裝、帆布條紋（世界裡唯一的紅褐） |
| `#957063` `#a4806f` `#b3907c` | 屋頂三階台地 |
| `#d6b7a0` | 女兒牆亮邊 |
| `#6f4c4b` | 牆的側面 |
| `#a292ab` `#8d7b92` | 落影、接觸遮蔽（偏紫的暖灰，不用黑） |
| `#f0b54a` `#a8742a` | 我方（天使金） |
| `#2f8fe0` `#17558f` | 對手 |
| `#e5484d` | 危險 |
| `#34292a` | 地圖外的桌面 |

單主色暖土，隊色才有飽和度，對手藍是唯一的冷色點綴。

### 畫法

- **牆**：牆實心先填側面色，屋頂往西北推 0.72 格畫回去，只露出南、東兩面；因為被牆實心裁切，不會蓋到可走區。側面加兩條石層線，屋頂是三階往內退的台地，加陶瓦細線與通風口。
- **地面**：六種材質（街道、泥地、木地板、市集、廣場、包點）依區域分區，交界畫路緣。包點是模板噴漆的框、角標、圓環與字母，用固定雜訊磨舊。
- **落影**：牆往東南掃 1.9 格，矮牆 0.7 格，低解析畫完放大取得柔邊；另一層是貼牆的接觸遮蔽。
- **道具**：矮牆依位置配成木箱、沙袋、桶，形狀就是碰撞矩形。牆邊道具畫在牆格內（走不到）。B 包點的井是 3×3 方塊，畫成方形石台裡的圓井。市集帆布平鋪在地上，不做棚頂，才不會遮人。
- **單位**：俯視模型兵。深色底座＋金環、肩膀、手臂、槍、背包、淺色頭盔；隊色在底座環與肩膀；兩階明暗永遠跟世界光向，不隨身體旋轉。持炸彈者背包變紅。
- **特效**：彈道是暖色漸層亮線，底下壓一道暗影（亮地面上純亮線看不見）；槍口星形火光加地面光暈；煙是 64 團亮面朝西北的不透明團塊，加地面落影；手雷有落地揚塵與紅色脈衝環；傷害數字沿用可玩版。
- **迷霧**：視線外換成「記憶圖」：同一張地面去飽和、乘淡冷灰。畫面還是白天，只是「現在沒看著」；視線內維持暖色日光，邊界一條細亮線。牆層畫在迷霧之上，所以斜牆邊界不會露出格子階梯。
- **區域名**：像噴在地上的路標，迷霧裡也讀得到。
- **HUD**：天使金語彙（墨黑面板、左緣金邊、右下切角、Barlow 斜體數字）。世界亮、HUD 暗，互不搶。

### 實作成本

| 項目 | 內容 |
| --- | --- |
| 離屏烘焙 | 地面、記憶圖、牆與道具三張（整張地圖，建議 24 px／格＝2880² px，每張約 33 MB，共約 100 MB） |
| 烘焙時間 | 樣張只烘鏡頭內 92 ms；整張地圖約 5 倍，估 0.5 秒，放載入時做 |
| 每幀開銷 | 實測 3.0 ms（1920×1080，含 7 個單位路徑繪製、迷霧三張全螢幕貼圖）；可玩版 30 TPS 插值到 60 fps 綽綽有餘 |
| 要做成 sprite | 單位建議預畫 32 方向 atlas，光向固定所以不能只旋轉一張；或維持每幀路徑（10 人以內撐得住） |
| 還要補 | 全部武器的槍身剪影、蹲姿、下包／拆包姿勢、屍體、火焰（燃燒瓶）、爆炸、閃光 |

### 優缺點

- 優：最直接回答「像 prototype」：材質、光影、落地感全有。迷霧最不傷白天感。地圖有地方感（赤岩鎮是層層土台的小鎮），可延伸到其他地圖。
- 優：和軍團戰「微縮沙盤、最終 3D」同一個世界觀，兩個電競項目看起來是同一家公司的產品。
- 缺：地面細節多，單位靠隊色環與深底座才跳得出來；縮放拉遠時要降級（遠看只畫底座與肩膀）。
- 缺：每種新材質、新道具都要畫，內容成本三案最高。

### 與天使金介面的銜接

HUD 直接用同一套 CSS 語彙，觀戰外框不用改。世界裡的金就是天使金 `#f0b54a`。唯一差異是「對手」：介面上對手是紅，世界裡對手是藍（紅在暖土上不跳，也會和危險色打架）。建議規則：世界裡對手藍，經營層與觀戰的文字維持對手紅。

## 三、方向 B 粗線漫畫

每一幀都像一格上了色的漫畫。

### 調色盤

| 色碼 | 職責 |
| --- | --- |
| `#f8ead0` `#f0d6a6` `#eab97f` `#fdf3df` | 地面平塗（街道、泥地、木地板、包點） |
| `#6346a0` `#7f61bf` `#4b3384` | 牆頂主色、亮帶、磚塊筆觸 |
| `#2f1f5c` | 牆的側面、網點 |
| `#1f1536` | 墨線（帶紫，不是純黑） |
| `#c9b6dc` | 硬邊落影 |
| `#ffc22e` `#e8891a` | 我方與其暗面 |
| `#19b9ee` `#0c7fc4` | 對手與其暗面 |
| `#ee3350` | 危險、傷害字 |

雙主色平衡：奶油與紫各占一半，隊色跳在上面。

### 畫法

- **牆**：紫色平塗，邊緣亮帶，屋頂只放幾組磚塊筆觸，其餘大膽留白。側面帶有直排陰影線。
- **地面**：平塗色塊，只在四散的小區塊畫石頭或泥點。
- **線寬**：三級，外框 6 px、結構 3～4 px、紋理 2 px。單位與特效用螢幕像素固定；牆與地面烘焙時以格為單位，縮放時會跟著變，正式版要依縮放檔位各烘一張或改成固定。
- **單位**：剪影先行。T 有頭巾尾巴、CT 有護目鏡；外框粗、肩膀一刀硬邊陰影。
- **特效**：彈道是尖的色塊加速度線；命中是白底爆形加紅字；手雷帶爆形框；煙是扇貝邊雲朵，硬邊暗面。
- **迷霧**：斜 45° 的紫色網點，顏色不變暗，資訊也不多給，是三案裡最有個性的迷霧。
- **包點**：地面一個爆形加字母，刻意用淺紫避免蓋過單位。
- **區域名**：漫畫旁白框。
- **HUD**：歪斜的墨線格，硬邊偏移陰影，數字用 Bangers。設定卡與結算是封面，集中線加放大的主角。

### 實作成本

| 項目 | 內容 |
| --- | --- |
| 離屏烘焙 | 地面、牆兩張（約 66 MB）；網點是一張小圖樣，每幀貼一次 |
| 烘焙時間 | 樣張 57 ms；整張地圖估 0.3 秒 |
| 每幀開銷 | 實測 2.3 ms |
| 要做成 sprite | 外框線寬必須固定，單位路徑每幀畫最省事；縮放時線寬不跟著變 |
| 還要補 | 爆形字庫、各武器剪影、受傷與死亡表情的誇張化 |

### 優缺點

- 優：辨識度最高，截圖一眼認得出，適合當行銷素材。單位在任何底色上都讀得出來。
- 優：內容成本比 A 低，留白就是風格。
- 缺：紫色是一個新主色，與天使金的「墨黑＋金」並列時像兩款遊戲。
- 缺：網點在非整數縮放下會產生摩爾紋（1280×720 看得到輕微干涉），正式版要用裝置解析度畫網點，或改成線條。
- 缺：調性偏輕快，與「經營一支電競戰隊」的擬真感有距離。

### 與天使金介面的銜接

只能部分銜接：金與墨線相容，但紫不在天使金色票內。要併用就得把牆改成墨黑或深藍灰，風格會失去一半的衝擊力；或者接受攻防戰是獨立品牌，靠觀戰外框的天使金過渡。

## 四、方向 C 極簡幾何

一張乾淨的戰術圖，語言是建築平面圖。

### 調色盤（八色，職責固定）

| 色碼 | 職責 |
| --- | --- |
| `#f7f4ec` | 看得見的地面 |
| `#e3ded2` | 看不見的地面、牆內輔助線 |
| `#b7b2a6` | 牆、點陣 |
| `#2a2d34` | 墨線與文字 |
| `#eca61f` | 我方 |
| `#1f6fc4` | 對手 |
| `#dd4148` | 危險與傷害 |
| `#ffffff` | 煙、面板底、矮牆 |

### 畫法

- **避開「太空像原型」**：不加材質，改加精度。三級線寬（牆 2.5 px、結構 1.5 px、輔助 1 px）、固定 5 格的十字點陣、視錐裡 10／20 格距離環、單位旁的引線標註、比例尺。空白因此變成「這張圖量得出距離」，而不是「還沒畫完」。
- **牆**：剖面填色（poché）加兩圈內縮線，靠線表現厚度，不用陰影。
- **矮牆**：白底空心框加對角線，和牆的「填滿」相對，一眼知道比牆低。
- **單位**：我方金色圓、對手藍色方（轉 45°），形狀本身就是第二辨識通道，色覺障礙也分得出。武器是一條線，長度即武器。炸彈是圓心的黑方塊。
- **特效**：彈道是實線彈頭加往後變短的節拍，靠節奏表現速度；命中是紅色四角框加引線標註的傷害；煙是橫線圓盤，標剩餘秒數；手雷是紅色弧與 3.5 格傷害範圍虛線。
- **迷霧**：底色換淺一階加細斜線，視線內挖開，邊界一條細墨線。
- **HUD**：白卡細墨線，沒有陰影、圓角、斜切；層次只靠字級與留白。

### 實作成本

| 項目 | 內容 |
| --- | --- |
| 離屏烘焙 | 地面、牆兩張（約 66 MB），也可以不烘、每幀畫向量 |
| 烘焙時間 | 樣張 32 ms；整張地圖估 0.2 秒 |
| 每幀開銷 | 實測 2.1 ms |
| 要做成 sprite | 不需要 |
| 還要補 | 幾乎只有蹲姿、下包等狀態符號，動態節奏要花心思 |

### 優缺點

- 優：成本最低，可讀性最高，戰術資訊（距離、範圍、秒數）最完整。
- 優：色覺友善，敵我不靠顏色。
- 缺：好看但冷，靠動態才有個性；靜止時比較像工具，不像「要發售的遊戲」，正好踩在使用者這次的評語上。
- 缺：標註太多時畫面會變成儀表板。煙的剩餘秒數觀察資料有給（`AreaEffect.ticksLeft`），手雷的引信沒有，所以樣張不標。
- 缺：與 A 的世界觀不連續，軍團戰的沙盤方向也接不上。

### 與天使金介面的銜接

金、紅職責相容，HUD 換色票就能接。但白底與天使金的墨黑底相反，從經營層切進來會明度大跳。

## 五、比較

| | A 沙盤 | B 漫畫 | C 幾何 |
| --- | --- | --- | --- |
| 解決「像 prototype」 | 最直接 | 直接 | 要靠動態補 |
| 白天感 | 強 | 強 | 強 |
| 單位可讀性 | 中，靠底座環 | 高 | 最高 |
| 迷霧美感 | 記憶圖，自然 | 網點，有個性 | 細斜線，乾淨 |
| 天使金銜接 | 完全 | 部分 | 色票相容、明度相反 |
| 與軍團戰一致 | 是 | 否 | 否 |
| 內容成本 | 高 | 中 | 低 |
| 每幀開銷（實測） | 3.0 ms | 2.3 ms | 2.1 ms |

## 六、建議

**選 A。** 理由：

1. 使用者的評語是「沒有像一個真正要發售的遊戲」。A 改的正是那層東西：材質、光影、地方感，而且不需要動鏡頭或玩法。
2. 它是唯一同時接得上兩邊的方向：HUD 直接是天使金，世界觀直接是軍團戰的微縮沙盤，將來上 3D 也有路。
3. 每幀 3.0 ms，效能不是問題；成本在內容，而內容可以分批補。

**建議借用**：C 的距離環與引線標註放進 A 的觀戰模式（全圖透視時當戰術疊層）；B 的命中爆形不借，會把 A 的調性拉走。

**若定 A，實作順序**：

| 優先級 | 項目 |
| --- | --- |
| P0 | 地面、牆烘焙與記憶圖迷霧接進 `render.ts`；預設縮放改 1.2；模型兵；HUD 換天使金語彙 |
| P1 | 全武器剪影、彈道與命中回饋、煙與火、炸彈標記、計分板、設定卡與結算 |
| P2 | 動畫細節（走路擺動、後座力、拋殼）、其他地圖材質、縮放拉遠的 LOD |

## 八、這份樣張沒做的

- 都是靜態畫面，沒有動畫，也沒有實玩驗證。效能數字是這台電腦內建瀏覽器的 Canvas 2D，60 幀平均，不含 `devicePixelRatio` 放大；整張地圖的烘焙時間與記憶體是依鏡頭面積推估，沒有實測。
- 彈道、煙、手雷之外的特效（火、爆炸、閃光）與屍體、蹲姿、下包姿勢都沒畫。
- 視線多邊形沒有模擬「自己蹲著時矮牆也擋」，這個場景自己是站著。
- 字型走 Google Fonts，離線時退回系統字，B 的 Bangers 數字差異最大。
