# 經營介面設計稿

2026-10-27 · **已定案：E 與 A 當正式介面方向**，兩稿已統一成同一套規格（見〇）。分支 `sketch/m4-ui-styles`（疊在 `feature/m4-game-ui` 上）。

同一個「基地」畫面、同一組假資料，四張設計稿各用不同的構圖，但做到同樣的設計等級：

- 以 1920×1080 設計，等比縮放到視窗。
- 有透視與廣角，圓形是重要元素。
- 有滑鼠視差、進場動畫、待機動畫。

開發時 `npm run web` 後開 <http://localhost:5173/web/sketch/>，四張並排；點進去全螢幕看動態。網址加 `?still` 是截圖模式，會略過進場動畫。

直接開 HTML 檔（雙擊或從檔案面板）看不到場景：動態是 TypeScript，要靠開發伺服器即時編譯，沒開伺服器就只剩版面。

工業極簡（舊 C）已經併進 E，從比較頁拿掉了；檔案 `web/sketch/ark.html` 還在，沒有刪。

## 〇、定案：E＋A 統一規格

E 是介面骨架（清單、面板、選手卡、比賽日），A 是基地首頁或世界地圖（從頂樓看整座城，點建築進各功能，進去之後就是 E 的面板）。兩稿共用 `web/sketch/angel.css`。

| 項目 | 規格 |
| --- | --- |
| 中性色 | 墨黑藍灰 `#0b0e14`／`#131823`／`#1c2535`，占畫面九成 |
| 文字 | 白 `#eef2f6`、灰 `#8b95a4`、深灰 `#5b6574` |
| 主色：天使金 | `#f0b54a`（亮 `#ffd98a`、暗 `#b9832a`）。只給我方、選中、主要行動（開戰） |
| 點綴：紅 | `#ff5d5d`（亮 `#ffa3a3`）。只給對手與警示（例如資金每週減少、未讀通知） |
| 細線、次要資訊 | 一律白或灰的半透明，不用顏色 |
| 字型 | 中文 Noto Sans TC，標題 900、微斜 −7°；數字與英文 Barlow Condensed 斜體 800；小標籤 Share Tech Mono、字距拉開 |
| 卡片材質 | 左緣一條粗邊（金＝我方或選中、紅＝對手、白＝一般），右下角切角；深色面板是深藍灰漸層加細斜紋 |
| 頭像 | 灰階後疊一層金色漸層（`.tinted`），不出現其他色相 |
| 共用元件 | 頂列（隊徽、W04、資金、名氣、資金跑道、信件）、斜切標籤 |

- **E**：拿掉冰藍（「v3 GOLD」圓、名氣錶、鏡頭外圈的虛線改成白）；出賽三人的小頭像改成染金；對手隊徽從隨機紫色改成紅色系；頂列與標籤樣式搬到 `angel.css`。

## 一、四張設計稿

### E　環形競技台（`apex.html`）

- **配色**：墨黑底、白、天使金為唯一主色，紅只給對手與警示（統一規格後已拿掉冰藍）。
- **版面**：不再是「左邊大角色、右邊斜磚牆」。
  - 王牌選手的圓形鏡頭放在畫面正中央，外圍是刻度環、評分弧、轉動的圓周文字。
  - 地上有一圈大的透視金環，六塊白色選單磚沿著金環後半圈排成半圓劇場，兩側較近較大、靠中間較遠較小，並微微轉向圓心。
  - 左下是選手名牌，右下是比賽日面板（雙方隊徽、我方三人、開戰圓鈕；圓鈕外圈 9 段就是賽季週次進度）。
- **動態**：
  - 整個場景隨滑鼠繞圓心轉。
  - 金環與點狀環在地上自轉。
  - 選單磚從地面依序升起，滑鼠移上去會浮起並掃過一道反光。
  - 開戰鈕會呼吸發光，鏡頭有掃描線。

A、B 第一版顏色太跳（四種高飽和色同時發光、沒有主次），已經重做配色與構圖。配色原則：中性暗色占大面積，再加「一個主色＋對比色點綴」或「兩個平衡的主色」，不摻其他色系。B 第二版（黃昏商店街）色還是太多、像復古街機，第三版改成賽博像素。

### A　夜城天台（`cyber.html`）

- **配色**：統一成 E 的天使金＋紅（見〇）。之前試過冷青＋暖橘、冷青＋洋紅、8 組試色（你一度選了紅黑白），都已收掉；試色版本留在 git `5822ef6`。
- **版面**：無人機視角，從我方大樓頂樓往下俯看整座城（水平視角約 80 度的廣角）。
  - 城市是程式算的 3D 方塊，約三千棟，開頁時畫一次。
  - 選單是釘在地標建築頂上的 AR 標籤，近大遠小。標籤平時白色半亮，滑鼠移上去變金，該棟建築的屋頂框線也跟著變金。對手總部用紅色標出。
  - 城中央是競技場，中央大道直直通往它；上空浮著「比賽日」卡。
  - 前景是我方屋頂：左邊是我方名單（目前選中，所以全亮），右邊是對手情報，中間是開戰鈕和開賽倒數。
- **動態**：
  - 競技場的 AR 地環在轉，三道探照燈在掃。
  - 大道上有車流，高樓頂有信標在閃，天上有飛行器拖著光尾。
  - 有細雨、霧帶，還有一道掃描帶由上往下掃過城市。
  - 整個鏡頭像無人機一樣微微浮動，也會隨滑鼠偏移；開頁時城市燈光由暗轉亮。

### B　霓虹雨巷（`pixel.html`）

- **配色**：雙主色。深靛中性色占八成；霓虹粉給招牌、對手、開戰；青給我方、框線、選中；另外只有白色當高光，沒有第四個色系。頭像與隊徽也只用雙色調（我方靛→青、對手靛→粉）。
- **版面**：雨夜的霓虹巷子，一點透視看向巷底。背景是 480×270 的低解析畫布，放大 4 倍。
  - 牆面、地面都是程式依透視逐格算出來的：一樓店面（粉光、青光、鐵捲門、沒開燈的玻璃）、店招、窗戶、冷氣機、落水管、牆上的直式霓虹。
  - 六個選單是兩側樓上掛的直式霓虹招牌（垂直於牆、正對鏡頭），近大遠小；選中的「戰隊」是青色，其他是粉色，滑鼠移上去變青。
  - 巷底是競技場，上空一圈光環（天使的光環），光環裡浮著全像「比賽日」。
  - 我方三人背對鏡頭站在路中間，輪廓有競技場打來的青色逆光；左邊人行道停著一台輪框發光的機車；巷口橫著一條掛燈籠的電線。
  - 下方左邊是出賽名單，中間是開戰鈕，右邊是助理對話框；面板是青色發光框，角落一朵粉色像素雲。
- **倒影**：濕路面的倒影以每一欄的牆腳為鏡線，從畫面上半部取樣；水窪整片映出來，濕柏油只映亮的霓虹。招牌、人、機車用自己的腳底當鏡線另外畫，倒影才不會歪。
- **字型**：繁中像素字型「俐方體 11 號」（OFL），字級都是 11 的整數倍。
- **動態**：
  - 招牌像霓虹管通電一樣閃幾下才亮，窗燈一盞盞亮起，有幾盞和小招牌會閃。
  - 下雨（雨絲把底下的顏色亮一階）、地上濺起雨點、水窪有漣漪，倒影會晃。
  - 光環的虛線圈在轉、三顆亮點沿著光環跑；一青一粉兩道探照燈在掃；燈籠在晃；拉麵店雨遮下冒蒸氣。
  - 遠景高樓有全像廣告和跑馬燈，隨滑鼠做小幅視差。

### D　戰術室（`table.html`）

- **版面**：鏡頭斜俯看教練的木桌，廣角透視。
  - 桌子中央是一座會慢慢轉的圓形微縮沙盤（河流、等高線、樹林、雙方部隊與旗子），沙盤中間插著對戰牌。
  - 六個選單是立在桌上的木製圓徽牌，沿沙盤後方排成半圓。
  - 三張選手卡斜立在前景的卡架上，桌上還有帳本、信封、籌碼。
  - 牆上是隊旗、桌曆、資金牌、兩個黃銅錶盤（資金跑道、名氣）、軟木積分板，開戰是一顆實體紅鈕。
- **配色**：胡桃木、黃銅、羊皮紙、沙盤綠，強調只有封蠟紅。
- **動態**：沙盤和刻字外圈反向轉動、檯燈微閃、燈下浮塵、錶針輕晃、物件從上方落到桌上、桌面隨滑鼠微傾。

它呼應軍團戰已定案的「微縮沙盤」美術。Unity 版可以從這張桌子直接把鏡頭推進沙盤開打。

## 二、比較

| | E 環形競技台 | A 夜城天台 | B 霓虹雨巷 | D 戰術室 |
| --- | --- | --- | --- | --- |
| 氣氛 | 頂級聯賽、俐落精緻 | 冷硬、情報戰、俯瞰全城 | 雨夜、街頭、賽博龐克 | 教練、謀略、溫暖 |
| 與軍團戰 3D 沙盤的一致性 | 中性 | 中性 | 反差最大 | 最一致 |
| 正式版素材量 | 低；主角鏡頭最好有插畫 | 低；城市是程式產生的 | 高：每個畫面都要一個像素場景，人物要手繪 | 中：材質與小道具 |
| 純程式能做到幾成 | 九成 | 九成 | 背景與介面九成，頭像只能示意 | 網頁七成，Unity 可做成真 3D |
| 資訊密集畫面（市場、帳本） | 好 | 好：AR 面板天生適合放數據 | 中：像素字大、一屏放得少 | 中：要做成「攤開的文件」 |
| 長時間遊玩 | 舒服 | 舒服；整體偏暗 | 舒服 | 舒服 |
| 手機版 | 要另排（環形要改直排） | 要另排（標籤要減量） | 要另排 | 要另排 |

## 三、定案前的建議（已採納）

3. B 留給特別場景；D 是和軍團戰同世界觀的備案，暫時擱置。
