# 整體 UI 走查盤點

2026-11-03 · 分支 `claude/game-ui-fix-cffad4` · 基準 main ae395cf（含 UX 2.1、Bot 2.4.3）

一句話：經營層的版面在 1920×1080 很完整，最大的問題是它整個是 1920 舞台等比縮放，1366×768 時所有字縮到七成、大量小字變成 8～9 px 不可讀；其次是賽段落幕後基地的「新的賽季」按鈕溢出、攻防戰回合開始時商店／回合橫幅／計分板三層互疊。攻防戰 HUD 本身（UX 2.1）沒有新的嚴重問題。

## 一、怎麼走查的

- 用無頭 Chrome（playwright-core＋系統 Chrome）實際開頁面，每個畫面在 1920×1080 與 1366×768 各截一張，共 170 張，挑 40 張放在 `docs/shots/ui-walk/`（檔名後綴 `-1920`／`-1366`）。
- 經營層用 `web/game.html?demo=7&content=shooter-1&weeks=N&to=畫面` 展示模式（不碰 localStorage），看了休賽期（W0）、例行賽第 3 週、比賽日五幕、破產、第 9 週決賽後的頒獎與賽段落幕；另外真的「創立戰隊 → 開幕」走過一次看存檔流程、選單、覆蓋確認。軍團戰暫代包只看了基地、戰隊、訓練三頁。
- 攻防戰用 `web/shooter.html`：開局卡、觀戰模式（跟隨、計分板、全圖、透視、按鍵表、速度選單、暫停、回合結束、賽後結算）、玩家模式（商店、對局、計分板、暫停）、經營層觀戰 `#watch`（載入、對局、計分板、全圖、回合結束、賽後對照）。
- 每張截圖同時跑一支稽核：列出實際顯示字級 < 10 px 的文字、超出視窗的元素。稽核結果在 `docs/shots/ui-walk/audit-1366.txt`。
- 嚴重度：**高**＝看不清、被切掉、按不到或明顯錯誤；**中**＝影響理解或操作但繞得過去；**低**＝觀感、一致性、小字。
