# 軍團戰 規格書 v0.3（草案）

Oct 23, 2026 · 取代 [v0.2](軍團戰%20規格書%20v0.2（草案）.md)。這版的變更：佔點模式的**後備兵力**（出生點、補給站、換兵、回血），**拿掉潰散與全軍潰敗**，**攻擊距離與視野加長**，觀戰的**戰爭迷霧**，以及**玩家親自指揮**。官方基準 AI 另見 [官方基準 AI 設計](軍團戰%20官方基準%20AI%20設計.md)。

沒有提到的部分沿用 v0.2：各兵種的招牌技能（第四節）、衝刺類技能的共通規則（第五節）、陣形（第六節）、地形與高度（第七節）。數值的單位同 v0.2：血量、攻擊為一般單位（引擎內部 ×10）；速度為規格刻度，遊戲內 ＝ 規格刻度 × 全域速度倍率 1.4。

## 一、變更總覽

| 項目 | v0.2 | v0.3 |
| --- | --- | --- |
| 佔點的兵力 | 500 點全部上場 | 共 1500 點，場上同時最多 500 點，其餘是後備 |
| 後備入場 | — | 場上沒滿時從出生點入場；滿了就把一團帶到出生點或自己的補給站換下來 |
| 回血 | 沒有 | 站在出生點或自己的補給站、5 秒沒受傷，每秒回 2% |
| 殘兵潰散 | 人數低於 20% 潰散，視同陣亡 | **拿掉**：每一團都打到最後一人，要不要撤回由 AI 決定 |
| 全軍潰敗 | 兵力低於 20% 判負 | **拿掉**：殲滅戰要打光對手全軍 |
| 攻擊距離 | 長槍 1.5、其他近戰 0.8～1.0、弓兵射程 12 | 長槍 2.5、劍士／輕步兵／輕騎 1.5、重騎 1.8、盾兵與弓兵近戰 1.0、弓兵射程 16 |
| 視野 | 步兵 10、弓兵 14、輕步兵／輕騎 12、重騎 8 | 步兵 14、弓兵／輕步兵／輕騎 18、重騎 12 |
| 觀戰的一方視角 | 只隱藏看不到的敵軍 | 加戰爭迷霧：自己各團的視野挖亮、其餘蓋暗 |
| 玩家 | 只能觀戰 | 藍方可以由玩家親自指揮 |

## 二、比賽流程

- **殲滅戰**：選兵 500 點 → 布陣（看不到對方）→ 開戰 → 5 分鐘時限。
- **佔點**：選兵 1500 點（場上最多 500 點，其餘自動成為後備）→ 布陣 → 開戰 → 8 分鐘時限。
- 戰鬥中沒有發育，只有老兵升級；佔點模式多了後備的調度。

粗體是這版改的。觸及是士兵中心到目標士兵中心的距離；陣形、相剋加成與傷害計算同 v0.2。

**槍林的迎擊與扣衝勁另有 1.5 格的判定距離**（不跟著觸及加長）：長槍觸及 2.5 格後，兩排槍林在騎兵撞進來之前就能刺好幾輪，把衝勁扣光，違反「兩排槍林輕重騎都衝得過去」（驗收 3a、3b）。所以近戰出手用 2.5 格，迎擊（不管冷卻的那一刺）與每刺扣 0.6 衝勁只對 1.5 格內的騎兵。

## 四、接觸前迷霧、老兵（殘兵潰散拿掉）

- 地形與高度完全公開；敵軍要進入己方任一軍團的視野（而且視線沒被地形擋住）才看得到；全軍共享視野。
- 樹林中的軍團隱蔽：敵人要在 3 格內（輕步兵 5 格）才看得到；主動攻擊後曝光 10 秒。
- 老兵：累積傷害達本團初始總血量的 50%、120% 升級，攻擊與血量上限 +10%、+20%。
- **沒有潰散**：人數再少也照常聽指令、照常戰鬥，直到最後一人陣亡。殘兵要不要撤回（佔點可以撤回後備回血）由 AI 決定。
- **沒有全軍潰敗**：殲滅戰要打光對手全部的團（含佔點的後備）。

拿掉的原因：潰散讓殘兵自動離場，AI 沒得選；佔點加了後備之後，殘兵撤回換兵本身就是要考驗的調度。

## 五、對戰模式

### 殲滅戰

地圖「河谷」（160 × 100 格），5 分鐘。打光對手全軍獲勝；時間到比剩餘兵力（點數 × 剩餘人數比例）。

### 佔點

地圖「大河谷」（240 × 150 格）。旗點、佔領進度、得分的規則同 v0.2 第九節：三個渡口（北橋 1 分、中央淺灘 2 分、南橋 1 分），圈半徑 5 格，15 秒佔滿才算佔領，佔領後每秒得分，圈內有敵人時暫停；先到 400 分獲勝，也可以直接殲滅對手；8 分鐘時間到先比分數、再比兵力（含後備）。

**後備兵力**（這版新增）：

| 規則 | 內容 |
| --- | --- |
| 點數 | 總共 1500 點，**場上同時最多 500 點**；場上的點數算全額，不管那團剩幾人 |
| 布陣 | `deploy` 回傳的團可以標 `reserve: true`；沒標但場上已經超過 500 點的，也自動成為後備。後備不用給座標 |
| 出生點 | 雙方各一個（藍方在西邊中線、紅方在東邊中線，離邊緣 10 格），半徑 8 格 |
| 補給站 | 北橋東岸、南橋西岸各一個（離橋 9 格，兩個互為 180° 對稱），半徑 6 格；**歸佔著那座橋的一方**，沒人佔時誰都不能用 |
| 召喚 `summon` | 場上加上這團不超過 500 點時，後備從出生點入場 |
| 換兵 `swap` | 場上的一團站在出生點或自己的補給站範圍內，就可以換上一團後備：場上的那團立刻撤回，後備在它的位置入場。換上後也不能超過 500 點 |
| 撤回 `withdraw` | 場上的一團站在出生點或自己的補給站範圍內，撤回後備 |
| 入場準備 | 召喚或換兵後要 10 秒才入場（這段時間不能再下指令給它）；入場位置附近有自己的團時往兩側錯開 |
| 撤回後 | 血量補滿、人數不變（死掉的不會回來）、所有指令清掉、老兵等級保留 |
| 限制 | 交戰中（3 秒內打過近戰）或衝刺中不能撤回或換兵；**數量不限**，要撤回幾團都可以，只要帶到範圍內 |
| 回血 | 站在出生點或自己的補給站、5 秒沒受傷，每秒回血量上限的 2%（不會復活死掉的人） |

設計目的：讓雙方打到最後一刻都有兵可以調度，前面被打光的一方不用乾等；補給站綁在橋上，搶橋多了一層意義（對藍方來說，南橋的補給站在自己岸邊、好守；北橋的在對岸，是前進基地。紅方相反）。

## 六、選手 API 變更

- `deploy(data)` 回傳的每團可加 `reserve: true`（佔點模式）。
- 初始資料：`map.spawns`（依 playerId 的出生點）、`map.supplies`（補給站座標與所屬的旗）；`capture` 新增 `budget`、`fieldCap`、`enterTicks`、`spawnRadius`、`supplyRadius`、`healPct`、`healQuietTicks`。
- 觀察資料：自己的後備也列在 `regiments`，帶 `reserve: true` 與 `enterIn`（還要幾個 tick 入場，−1 ＝ 沒排定）；狀態多了 `reserve`、`entering`；新增 `fieldCost`（場上點數）、`fieldCap`。看不到對手的後備。
- 新指令：

| 指令 | 參數 | 說明 |
| --- | --- | --- |
| `summon` | 後備的 id | 從出生點入場 |
| `swap` | 場上那團的 id、`with`：後備的 id | 在出生點或自己的補給站換兵 |
| `withdraw` | 場上那團的 id | 在出生點或自己的補給站撤回後備 |

- 事件：`enter`（入場）、`withdraw`（撤回），只有自己看得到。
- 被拒絕的指令照舊回 `rejected` 事件（附原因）。
- 比賽結果的勝因：`annihilation`、`score`、`time`（拿掉 `collapse`）。

## 七、觀戰

沿用 v0.2，新增：

- **戰爭迷霧**（一方視角）：選某一方的視角時，自己各團的視野範圍（含高度加成）挖亮，其餘蓋一層暗色；看不到的敵軍不畫。迷霧是視野圓的近似，沒有算地形擋視線（引擎判定看不看得到時有算），之後可以改成逐格的視線版本。上帝視角沒有迷霧。
- 出生點（隊伍色帳篷）、補給站（補給十字，顏色＝佔著那座橋的一方）、入場倒數、名冊的後備區。
- 撤回、入場的播報。

## 八、玩家指揮（新增）

為了讓人可以直接下場測試規則與 AI，藍方可以改由玩家指揮（紅方仍是 AI）。玩家走跟 AI 一樣的指令通道：每 0.5 秒的決策點交出最多 10 個指令、受同樣的規則限制，所以玩家能做的事 AI 都能做，反之亦然。

| 操作 | 效果 |
| --- | --- |
| 左鍵 | 選取（Shift 加選、拖曳框選）；Ctrl+A 全選、Esc 取消 |
| 右鍵 | 點地面移動（多團在目的地排成一列，依目前左右位置分配不交叉）；拖曳＝指定移動後的朝向；點敵軍＝攻擊 |
| Q | 招牌技能，朝滑鼠：槍林、突擊、切入、衝鋒、齊射；盾兵開關盾牆 |
| E | 收起槍林；盾兵切換舉盾／持盾 |
| A | 邊走邊打到滑鼠位置（沒有選取時是鏡頭平移） |
| H／T／F | 堅守、轉向滑鼠、跟隨滑鼠下的友軍（保持目前相對位置） |
| Z X C V | 橫陣、方陣、楔形陣、圓陣（兵種不能用的陣形會提示） |
| 名冊點後備 | 沒選取或選了多團＝從出生點入場；只選一團場上的＝跟它換兵 |
| WASD、中鍵拖曳 | 平移鏡頭；滾輪縮放 |

- 設定頁選「玩家（你來指揮）」後可以自訂兵力：各兵種場上、後備各幾團（殲滅戰沒有後備），超過點數上限不能開戰。布陣自動完成（步兵在前、弓兵其次、騎兵與輕步兵在後，從中線往兩側排）。
- 指令被拒絕時畫面跳出原因（例如「換兵：不在出生點或自己的補給站」）。
- 暫停中也能下指令，開戰後才交給引擎；速度 0.5、1、2、4 倍。
- 玩家看不到對手的資訊：對手的陣容、戰略意圖、各團意圖、看不到的團（名冊只列出現在看得到的）、看不到的播報都隱藏。計分條的雙方兵力百分比與旗點狀態仍公開（同記分板）。

## 九、驗收測試

一團對一團的 19 項（v0.2 第十二節的 17 項，其中第 3 項拆成輕騎、重騎兩項，第 16 項拆成重騎對撞、重騎撞輕騎兩項）。因為沒有潰散，第 9 項改成「劍士損失 ≥ 50% 並被殲滅；重騎損失 < 15%」。

另有官方基準 AI 的 13 項情境測試（見 [官方基準 AI 設計](軍團戰%20官方基準%20AI%20設計.md)），以及佔點、後備、玩家自動布陣的單元測試。

## 十、待確認

1. **全域速度倍率**：仍是 1.4。
2. **殲滅戰的節奏**：沒有潰散之後，實力接近的對局（例如統帥鏡像）多半打到時間到。要不要加長時限、改成比剩餘兵力的門檻，或加入其他收尾機制，第 3 階段（自我對戰聯賽）再看數據決定。
3. **槍林的迎擊距離**：目前 1.5 格（觸及 2.5 格）。若之後想讓長槍更早刺到衝來的騎兵，就要同時提高騎兵的衝勁，否則兩排槍林會擋得住衝鋒。
4. **平衡基準**：建議以點數平衡（同點數、沒有相剋時大致打平）。
5. 戰爭迷霧要不要做逐格視線的版本。
