## 一、規則定案（本步驟實作；數值待審，步驟 5 試玩再調）

### 投擲
- `throw { grenade, deg, power }`：手上要有該道具（不需切換到道具槽，投擲動作與開火互斥，投擲後 `ticks(0.5)` 內不能再投）；`power` 0～100 線性對應投擲距離 0～`maxThrowRange`（25 格）。
- 飛行：從投擲者位置沿 `deg` 直線以 `flySpeed` 前進；碰牆**反彈一次**（以牆面法線鏡射，剩餘距離繼續），第二次碰牆就停；走完距離就停（落地）。飛行中不碰人。
- 生效時機：閃光、煙霧、手雷 ＝ 投擲後 `fuseTicks`（1.5 秒）到了就在當下位置生效（可能還在飛）；燃燒瓶／燃燒彈 ＝ **落地或第二次碰牆時**立刻生效（`fuseTicks` 1.0 秒作為上限，飛超過也生效）。
- 聲音：落地或反彈發 `grenadeLand`（`actionRange` 15 格）；手雷與閃光生效發 `explosion`（60 格）；煙霧與燃燒生效發 `grenadeLand`。

### 煙霧
- 生效後 `smokeBloomTicks`（1 秒）內半徑從 0 線性長到 3 格，持續 `durationTicks`（18 秒）後消失。
- **擋視線**：敵我判定（`visibility`）、雷達、掉落物可見、閃光的視線檢查都要把場上煙霧傳進 `lineOfSight`。不擋子彈、不擋聲音、不擋移動。
- 撲滅火：煙霧生效（含擴散中）時，與任何火圈重疊（兩圓心距 < 兩半徑和）的火立即消失；火落在已有煙霧裡也不會點燃。

### 閃光
- 生效時，對**所有活著的人（含隊友與自己）**：距離 ≤ 15 格、且從該人到爆點有視線（牆與煙霧都擋）才致盲。
- 致盲時間：先依朝向定基礎值——爆點方向與朝向夾角 ≤ 60° 正對 `flashFrontTicks`（2.0 秒）、≤ 120° 側向 `flashSideTicks`（1.0 秒）、其餘背對 `flashBackTicks`（0.3 秒）；再乘距離係數 `1 − d／(2R)`（貼臉 100%、15 格外緣 50%）。取整數 tick。
- `blindTicks` 取較大值（不累加）。致盲期間 enemies／radar 為空（已有）、`effects`／`items`／`projectiles` 也為空；自己與隊友資料照給；仍可移動、開火、投擲。

### 手雷
- 生效時對半徑 3.5 格內所有活著的人（含隊友、自己）：傷害 ＝ `98 × (1 − d／R)`（線性，取整）；有視線才算（牆擋，煙霧不擋）。護甲：吸收 `heArmorPct`（50%）並扣甲值（同子彈的扣甲方式）。隊友 30%（`FRIENDLY_FIRE_PCT`）。
- 擊殺歸投擲者：獎金 `grenadeKillReward` 300；炸死隊友 −300（隊殺）；炸死自己 −300、不算擊殺。

### 燃燒瓶／燃燒彈
- 落地生效：半徑 3 格的火圈，持續 7 秒；每 `fireTickInterval`（0.2 秒）對圈內活著的人造成 `40 × 0.2 = 8` 點傷害（**不吃護甲**）；隊友 30%。擊殺與獎金規則同手雷。
- 火圈是圓，不受牆形狀影響（2D 簡化；待審）。

### 其他
- 道具死亡**不掉落**（維持步驟 2 的決定）。
- 道具數量：投出後從 `Player.grenades` 移除。
- 回合結束（進入下一回合）時清除所有飛行中的道具、煙霧、火。

1. `src/shooter/sim.ts`：投射物、煙霧、火、閃光的狀態（全部整數、**計入雜湊**）、每 tick 更新順序建議：指令 → 轉身 → 移動 → 投射物飛行與生效 → 開火 → 火焰結算 → 炸彈 → 回合判定。煙霧接進 `visibility()`、`itemVisible()`、閃光視線。
2. `src/shooter/api.ts`：`effects` 已有（填煙霧與火，煙霧半徑給當下實際半徑）；新增 `projectiles: readonly { kind: GrenadeId; x: number; y: number }[]`（看得見的飛行中道具：視錐內有視線或 2 格內）。其他欄位不動（要動就在報告說明）。
3. `src/shooter/config.ts`：缺的常數補上（投擲冷卻、閃光距離係數、HE 視線規則等），都加註解與「待審」。
4. `bots/shooter-practice.js`（v3）：全買局 T 多買一顆煙霧，接近目標炸彈點 15 格內朝點中心丟一次；全買局 CT 多買一顆閃光，雷達或視野出現敵人且距離 10～20 格時朝敵人方向丟一次。只做這兩條，不寫戰術。
5. `src/shooter/acceptance.ts`、`test/shooter.test.ts` 追加（腳本控制器為主）：
   - 投擲：力道對應距離（0／50／100）；碰牆反彈一次後繼續、第二次停；投擲後道具從背包移除；沒有該道具時忽略；冷卻。
   - 煙霧：擴散中半徑線性成長；煙後的敵人不在 `enemies` 也不在隊友的 `radar`；子彈穿煙照打；18 秒後消失；煙撲滅火。
   - 閃光：正對／側向／背對三種致盲時間；距離係數；牆後與煙後不致盲；致盲期間 enemies／radar／effects 為空、me／teammates 仍在；隊友與自己也會被閃；取較大值不累加。
   - 手雷：中心與邊緣傷害值；護甲吸收與扣甲；牆後不受傷；隊友 30%；擊殺獎金 300、隊殺 −300、自殺 −300。
   - 燃燒：每 0.2 秒 8 點、不吃護甲；7 秒後消失；站在火裡 2 秒掉 80；煙霧撲滅後不再扣血。
   - 聲音：`grenadeLand`、`explosion` 的距離與方向量化。
   - 回合交接清除所有道具效果。
   - 確定性：同種子雜湊、回放重播（含道具）照過；陪練 Bot 短賽制對打無例外。
6. CLI：`shooter batch` 的統計加每隊平均每回合投擲數與閃光致盲總秒數（看道具有沒有在用）。
