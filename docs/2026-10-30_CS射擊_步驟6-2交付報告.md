## 二、架構（團隊層）

```
decide(obs)
 ├─ 感知 → 戰術 Tactics.update
 │    ├─ trackTeam   隊友陣亡（換血、E:dead）、我打出的傷害（估計對手血量）
 │    ├─ readChat    計畫 P:、買法 B:、事件 E:（事件依警覺延遲處理）
 │    ├─ lead        指揮：選計畫、執行／輪轉／回防時機，計畫字串變了就重喊
 │    ├─ buy         指揮先定買法並喊，其他人等買法（最多 1 秒）再買
 │    ├─ report      看到敵人 → E:contact <區域> <人數>
 │    ├─ tGoal／ctGoal 目標點、守位、路線、下包／拆包、想丟的道具
 │    ├─ overlay     躲閃光（躲到看不到爆點的格或轉身）、換血、追殘血
 │    └─ util.step   道具：瞄準、丟、背對
 ├─ 導航、戰鬥（6-1，介面不變）
 └─ 合成：移動（自保 > 交戰 > 架槍 > 戰術 stop > 導航）、瞄準（hard 躲閃光 > 交戰 > urgent > 戰術 look > 沒事看哪裡）
```

### 隊內協調（全部靠 say）

| 字串 | 誰喊 | 意思 |
|---|---|---|
| `P:go A 0` | 指揮 | 直接去（6-1 格式，探頭照常） |
| `P:rushA 0` | 指揮 | 五人走路線 0、不探頭不靜步、前面的人丟閃 |
| `P:splitA 0 2`、`… go` | 指揮 | 主力 3 人走路線 0、第二組 2 人走路線 2 到各自的待命格；兩組都到了（或 32 秒）喊 go |
| `P:default A 0 1`、`… >B` | 指揮 | 主力 3 人到 A 路線 0 的待命格、2 人到 B 路線 1 的待命格控圖；`>B` 表示執行 B |
| `P:fake B 0 1`、`… >B` | 指揮 | 主力去 B、佯攻組到 A 開槍丟雷，4 秒後主力執行 |
| `P:hold A=2 M=1 B=2[ rot=B][ go]` | 指揮 | CT 配置；`rot` 輪轉目標；`go` 回防集結完畢一起進 |
| `B:full／force／half／eco` | 指揮 | 全隊買法 |
| `E:contact <區域> <人數>` | 看到敵人的人 | 同一區域人數變了或隔 1.5 秒才再喊 |
| `E:dead <區域>` | 指揮 | 隊友陣亡處 |
| `E:planted <點>` | 雙方指揮 | 炸彈下了 |
| `E:flash x y tick`、`E:smoke x y` | 丟的人 | 閃光爆點與爆炸 tick（隊友躲）、煙霧位置（閃光選點避開） |
| `E:kit` | 有拆彈器的 CT | 隊友看不到別人的拆彈器，靠這句決定誰拆 |

指揮＝活著的最小 playerId，只接受 id 比自己小的人的計畫；指揮死了下一個人重喊目前的計畫（T11）。第一個計畫與買法立刻處理，之後的計畫變更與事件晚 `eventDelay`（警覺 0→100：4→0 次決策）才處理。

### T 方

- **選計畫**（指揮，凍結時間）：eco → rush 60%；對方多半 eco（上回合我方贏、對方連敗補償 ≥ 2 階）→ rush／split 為主、default 提早 40% 執行；其他 default 32%、split 30%、rush 12%＋20%×侵略、fake 18%。點依兩點最近的成敗加權（贏 +1、輸 −1，夾在 ±2）。旋鈕 `plan` 可以固定種類。
- **分組**：主力＝持彈者＋隊內序號最小的兩人，其餘第二組；組內第 0 個（持彈者排最後）是突破手（閃光），隊內序號 1、3（其次 2、0）是煙霧手。第一次知道計畫時分好，之後有人陣亡不重分。
- **待命格**：路線最後一個交界（包點入口）外側、距離場多 9 格、在路線附近、包點守點位看不到的格；附近每人一格（彼此隔 1.6 格）。佈置時可以探頭，靠近待命格 10 格內靜步（走位 ≥ 30）。
- **執行**：煙霧手先丟煙（封「最可能架這個入口」的位置：記得的敵人優先，否則看得到入口、最遠的守點位），突破手再丟閃，其他人在待命格等閃光爆完（最多 3 秒）才進；丟道具的人最多在待命格待到執行後 4 秒。執行時不探頭不靜步。持彈者去下包位下包（看得到敵人就不下）。
- **時間**：剩 35 秒指揮強行執行最近的點；指揮沒喊、剩 32 秒時每個人自己照最近的點執行（T12）。
- **下包後**：守包點的守點位（看 CT 最近的入口的先）＋下包位，離炸彈 14 格內，依名次分配；不追出去（T5）；看到或聽到拆包就把燃燒／手雷丟到炸彈上。

### CT 方

- **配置**：A＝旋鈕 `ctSplitA`（預設 2）、B 2、其餘中路。每點前兩人用 6-1 的守點位（最可能來的入口的兩個）；疊到 3 人以上時，多出來的人也看那個入口（另外算看守位）。中路位：T 路線經過的交界中，經過的路線最多、離兩點都 ≥ 15 格、CT 比 T 早 5 格以上到的那個，守在它 CT 側 8～20 格（赤岩鎮看拱門｜中央大道一帶、沙城看中路門）。狙擊手（開打時拿狙擊槍的人）拿長對線位（包點 10 格內、看得到入口 16～28 格）。
- **對方的傾向**：記最近 4 回合對方打哪一點，3 回合以上而且差 2 → 那點多一人（從中路拿）；差 3 以上 → 那點疊 4 人、另一點只留錨點。
- **輪轉**：某點估計 ≥ 2 人（自己記得的敵人、收到的接觸、隊友在該點陣亡，取大）而且比另一點多 → `rot=X`。另一點的錨點不動，其他不在 X 的人到 X 的回防待命位（CT 路線進包點的入口外側）守著。
- **回防**：炸彈下了全員往炸彈的點；點外的人先到待命位集結，指揮在「點外的人都到了」或「時間只夠現在走」時喊 go，然後一起進（T3）。進點時有閃光的人朝炸彈附近記得的敵人丟閃。拆的人：拿拆彈器而且離炸彈不比最近的人遠 8 格以上的人，否則最近的人（T14）；其他人到炸彈附近的守點位看入口（T10）。
- **保槍**：誰都來不及（走過去＋拆的時間 > 炸彈剩餘時間）、或只剩自己對 3 人以上而且紀律 ≥ 50、侵略 < 60、下回合買不起 → 離炸彈 22 格以上（CT 出生區）。
- **燃燒**：兩個以上記得的敵人（1.5 秒內）在自己守的點的入口外 16 格內 → 燒入口外側。
- **殘局**：只剩自己、對方 ≤ 2 人、侵略 ≥ 65 → 去最後知道敵人的地方找人；否則守位打時間（T6）。

### 經濟

- 指揮買法：手槍局 → force（護甲）；全隊 ≥ 4 人買得起全買（步槍＋甲＋拆彈器＋閃），或對方多半 eco 而 ≥ 3 人買得起 → full；對方賽點或半場最後一回合 → force；手槍局贏了的第二回合 → half；這回合 eco 下回合 ≥ 4 人能全買 → eco；旋鈕 economy=2 → force；平均錢 ≥ 衝鋒槍＋甲＋600 → half；其餘 eco（T7）。
- 個人：照買法；狙擊手（隊內序號＝`awpSlot`）錢夠買狙擊槍；道具依隊內序號：T 突破手閃 2、支援煙 1 閃 1、另有燃燒、手雷；CT 每人至少閃 1，序號 0、3 燃燒；備彈不到一半補。紀律 < 50 的人有機率在 eco 偷買沙鷹、half 時錢夠就自己全買。

### 道具與閃光安全

- 彈道：照引擎飛法模擬，路上碰到牆就不丟；丟前要靜止、瞄準超過反應延遲（避免方向被夾到視錐邊界）、2 倍反應延遲內沒看到敵人（閃光、煙霧）。
- 閃光爆點：包點區域內、入口內側 8 格內，依「看得到它的沒清過守點位、記得的敵人、聽到聲音的位置」排序（中間隔著我方煙霧的不算），後面接預設點；選「預期閃到敵人 ÷ 閃到自己人」最好的，照計畫執行時比值 ≥ 2（4 步內躲得到的隊友不算），rush 時比值 ≥ 5 而且要可能有人看得到。爆點 4 格內有看得到它的隊友、最近 1.5 秒開過火的隊友、或隊友正看著爆點附近的敵人 → 不丟。
- 躲閃光：閃光到 2R（30 格）都會致盲，所以致盲距離內看得到爆點就躲到 7 步內看不到的格，沒有就轉身；快爆時（反應延遲＋轉身時間內）交戰中也轉身停火；爆之前不走回視線、不轉頭去丟自己的道具。

## 七、與任務書的出入、我自己定的事（逐條）

1. **計畫字串格式**是我定的（第二節表）。任務書例「`P:default A=2 B=2 mid=1`」：我的 default 是「主力 3 人一個點、2 人另一個點控圖」而不是「2 人中路、3 人一側」，因為中路在兩張圖上不一定是「蒐情報」的好位置，另一點的待命格能直接聽到／看到守方；情報決定執行哪一點（`>B`）。6-1 的 `P:go`、`P:hold A=3 B=2` 仍可解析。
2. **default 的「情報」**只用兩點附近估計的敵人數（記得的敵人、接觸、隊友陣亡）；開打一半時間後兩點差 ≥ 2 就提早打少的那點。
3. **fake 製造聲音**＝佯攻組到待命格開 0.4 秒槍＋往包點中心丟手雷／燃燒；不會「假打一點再轉」到同一點的另一入口。
4. **CT 配置 2／1／2**：任務書「預設 2（A）／1（中）／2（B）」照做；每點兩人仍看同一個入口（6-1 實測比分散好），「B 西門沒人看」改由中路位處理：赤岩鎮的中路位守在北街看拱門／中央大道，看得到往 B 西門的路。**另外加了「對方連打同一點就疊人」**（任務書沒有）：對陪練（永遠打最近的點）效果很大，鏡像影響小（基準的 T 會依成敗換點）。
5. **輪轉**：輪轉的人到包點**外面**的回防待命位守著，不直接進包點（進去會一個一個送）；炸彈下了才和回防一起進。任務書「輪轉走不會被對方同時看到的路」沒有另外做，靠 A* 的危險格成本。
6. **回防**的閃光只在「炸彈附近有記得的敵人」時丟；**煙霧 CT 沒有用**（CT 部分角色會買煙但沒有回防封入口的規則），「拆包前燒包點掩體後方」也沒做。
7. **拆彈器優先**：隊友的拆彈器看不到，加了 `E:kit`（開打或拿到時喊一次）；任務書沒有這個事件。
8. **保槍**：「時間不夠」以全隊最快的人（走過去＋拆）算；「1 對 3 以上、紀律高、下回合買不起」只在下包後判斷。保槍點簡化成 CT 出生區（離炸彈 ≥ 22 格時），沒有找真正的躲藏點。
9. **殘局**：1vX 的「拆包騙」沒做；T 方殘局沒有特別規則（下包後守包、沒下包照計畫執行）。CT「侵略高主動找人」用 `huntAggr` 0.65。
10. **換血**只做「朝隊友陣亡時面對的方向架槍 1.5 秒（站住）」，沒有主動補位。
11. **事件**：`E:contact` 只由「看到」產生；聽到槍聲不喊（聲音只有方向沒有人數，誤報多）。T2 的情境標題是「聽 B 槍聲」，實際佈置是三個 T 在 B 點裡朝外開槍（B 的守方看得到他們）。`E:dead` 只由指揮喊（每個人都看得到隊友陣亡，避免五人重喊）。
12. **經濟**：手槍局喊 `B:force`（買護甲）；任務書沒說手槍局的買法字串。沒有做丟槍給隊友。「每人至少一顆閃」只在全買時保證（half 買一顆道具、force 一顆）。
13. **道具**：每種道具每人每回合一次（同任務書）；閃光多了「划算檢查」與「可能有人看得到」的條件，並且依引擎規則把致盲距離當成 2R。**反閃（聽到腳步丟過去）沒做**；手雷「下包後丟向拆包者常站位」改成「聽到／看到拆包就丟燃燒或手雷到炸彈上」。
14. **聲音紀律**：佈置時靠近待命格靜步（走位 ≥ 30）、執行與 rush 不靜步、回防集結靠近時靜步；6-1 的「附近有敵人就靜步」照舊。
15. **不追殘血**做了（6-1 留下的）：用自己子彈的 `damage` 估計目標血量，紀律 < 50 的人會追。
16. **T8 判定**：「任一人連續 2 秒原地不動」排除包點 6 步內（進點後守位是故意站著）與下包中；另外驗 split 從兩個不同區域進點。
17. **T9 判定**：任務書是「40 場統計」；情境每個種子跑短賽（每半場 6 回合）：鏡像兩張圖各一場（兩邊都算）＋陪練雙邊各一場（只算基準），隊友致盲 < 敵方 20%。40 場的統計（對陪練）在第四節：赤岩鎮 19.2%、沙城 7.5%（合計 12.9%）。**赤岩鎮的 19.2% 很接近門檻**（第八節）。
18. **情境的佈置**都由地圖資料算（包點矩形、出生區、步數距離場、牆）；不參與的人放進地圖角落的牆格（誰都看不到）。T4 讓 Bot 自己的指揮選 split 的點與路線，兩點各放一個躲在「包點外最看不到的角落」、每秒朝牆開一槍的 CT；T13 用「連殺兩回合」造出對方連敗的經濟狀態。
19. **鏡像**：任務書寫「兩邊整場勝率各在 35～65%」、交辦寫「T 回合勝率在 35～65%」，兩種都列（第四節），都在範圍內。
20. 旋鈕 `ctSplitA` 預設從 3 改成 2（配合 2／1／2）；`role` 的 1～3、5 沒有做（角色由隊內序號決定）。
21. **探頭**：執行中（rush，以及 split／default／fake 喊執行之後）不探頭、不靜步；佈置與 `P:go`（6-1 的直接進點，P8 用）照 6-1 探頭。

## 八、給步驟 7（選手衍生與強度表）的注意事項

- **檔案大小**：190 KB，離 200 KB 上限只剩 10 KB。步驟 7 若要再加邏輯，先把 `tactics.js` 的註解精簡或把重複的掃描（`stageSpots`、`watchSpots`、`sniperSpot`）合併。
- **最影響強度的參數**（依這次調整的經驗）：
  1. CT 配置與疊點規則（`ctSplitA`、`ctB`、疊點門檻）——對陪練 CT 回合勝率主要來源。
  2. 閃光的划算比值與躲閃光步數——直接決定 T9（隊友致盲比例）；赤岩鎮對陪練 19.2% 只剩一點空間，調強度時要一起看 `flashTeamPct`。
  3. `rotateHeat`、`retakeGather` 與回防 go 的時機——回防成功率只有 46～49%（對陪練），是 CT 下一個可以進步的地方。
  4. T 計畫權重——鏡像裡 split 勝率最高（赤岩鎮 72.3%）、rush 最低（52.9%），步驟 7 可以依角色或侵略調。
  5. 6-1 的戰鬥參數（`aimErr`、`react`、`outnumber`）仍是個人強度的主軸：aim 20→80 回合勝率 58.5%→80.7%。
- **屬性梯度**：aim、aggression 方向對；discipline 對陪練幾乎沒有梯度（風格屬性），步驟 7 驗單調時建議只驗 aim、reaction、awareness、aggression，discipline、movement 當風格。
- **五角色的預設屬性**（建議，50 為基準）：
  - 突破手（隊內序號 0、閃 2）：aggression 70、reaction 65、movement 60、discipline 45
  - 狙擊手（`awpSlot`）：aim 75、discipline 65、aggression 35、awareness 60
  - 支援／道具手（序號 1、3，煙＋閃）：discipline 70、awareness 65、aggression 40
  - 錨點（CT 每點第一人、燃燒）：discipline 75、awareness 70、aggression 30
  - 游擊（CT 中路、T 第二組）：awareness 70、movement 65、aggression 55
