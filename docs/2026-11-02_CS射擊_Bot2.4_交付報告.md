## 本次範圍

以使用者同意的四項基本能力為範圍，保留 2.3 快照作對照。沒有改引擎 1.2.0、選手 API 1.1、地圖、屬性成長與反應延遲規則。

| 能力 | 實作 | 基本版的邊界 |
| --- | --- | --- |
| 敵情推斷 | `belief.js`：失聯敵人沿八方向合法通路擴展候選格，禁止斜穿牆角；信心衰減、可靠掃描排除、重新接敵收斂、全滅清除。候選只用於規劃及預瞄 | 不是敵人的真實座標；聲音不假造身分，推測不建立可射擊目標 |
| 任務重評 | `mission.js`：根據任務、剩餘時間、實際通路與操作時間，統一中斷額外預瞄、失聯架槍、追擊與道具準備。回防／保槍每次重評，持續拆包也檢查可行性 | 實際看見敵人仍可交戰，自保與已投出閃光的安全處理保留；不是完整戰術搜尋 |
| 團隊協同 | `cooperation.js`：近距離接戰由最近空閒隊員跟進、死亡後短時接替，避開隊友射線；守點分時分配可見入口、確保仍作常態掃描；死亡後組內職責重排，回防忽略來不及到場的等待對象 | 依個別觀察與公開隊友狀態協調，沒有跨 Bot 共享隱藏記憶或庫存 |
| 跨回合適應與欺敵 | `adaptation.js`：分陣營、有證據門檻與時間衰減的進攻點／節奏／計畫結果記憶。佯攻捕捉已確認的敵方輪轉，或先試探空入口再轉打；缺乏資訊時由既有期限收尾 | 未觀察不記成沒有，少量樣本不大幅改守點；記憶僅存在同一場比賽 |

## 重要修正與驗收反例

- **換邊**：使用公開比分辨認上一回合結果，放進原陣營模型；不把新陣營的資料混入舊模型，也不猜測跳過數個回合的結果。
- **期限導航**：緊急時減少舊敵情與偏好路線造成的繞行，仍保留火區成本及即時自保；期限解除時重新恢復正常成本。
- **準備階段**：凍結倒數與回合目標期限分開；R2 曾驗出混用倒數造成狙擊手走錯準備路線，已修正並加上反例。
- **解除輪轉**：接敵失聯維持未知；需要近期可靠清點才因空點解除輪轉。
- **拆包**：隊友持續拆包的已觀察時間會扣除，避免每次重算完整五／十秒；自己明知來不及完成時能取消動作，局勢改善後也能解除保槍。
- **守角**：初版固定看入口導致 T2／R4 漏看點內接敵，已改為短暫補看與常態掃描交替；不靠放寬測試修正。
- **佯攻**：增加實際試探階段，受阻就中止；「探到空點」可由正常行動觸發，不只存在於計畫選擇分支。
