## 一、目標

打開 `web/shooter.html`，選陣營，和 9 隻陪練 Bot 打完一整場 MR12，看得到視錐迷霧、雷達、煙閃雷火、購買選單、HUD，死後能看隊友視角，比賽結束有計分板。**畫面只能畫玩家觀察資料裡有的東西**，視野公平自然成立。

## 二、規則定案（本步驟需要動引擎的部分，只有這兩條）

| # | 事項 | 定案 |
|---|---|---|
| 1 | 投擲方向（步驟 3 報告第 7 條） | **投擲方向夾在視錐內**：`throw.deg` 與當下朝向的夾角超過 fov／2 時，夾到邊界（不拒絕）。玩家往滑鼠方向丟本來就在視錐內；Bot 要往背後丟得先轉身。加測試。 |
| 2 | 人類輸入頻率 | 人類控制器的指令**每個 tick 套用**（`takeRealtime` 模式，同 RTS 的 `HumanController`），Bot 仍每 3 tick；回放把人類指令按實際 tick 記錄並能重播。轉身上限、散佈、冷卻對人類一視同仁，不另開後門。 |

其他規則一律不動（火圈不受牆擋、自傷 100%、道具不掉落、角色不碰撞都留到步驟 5 試玩後定）。

## 三、交付清單

1. `src/shooter/human.ts`：`ShooterHumanController`（實作 runner 的控制器介面）：`enqueue(cmds)`、`takeRealtime()`；`decide()` 回傳空陣列（指令已由 realtime 路徑套用）。`src/shooter/runner.ts` 加上非決策 tick 也取 realtime 指令並錄進回放的路徑；回放重播要能重現人類指令（加測試：腳本模擬人類每 tick 下指令 → 錄回放 → 重播雜湊相同）。
2. `src/shooter/sim.ts`：投擲方向夾視錐（第二節第 1 條）。
3. 網頁：`web/shooter.html`、`web/shooter.css`、`src/web/shooter/`（`main.ts`、`worker.ts`、`protocol.ts`、`render.ts`、`input.ts`、`hud.ts`、`buy.ts`、`setup.ts`，怎麼切可調整）；`vite.config.ts` 加入口；`tsconfig.web.json` 若有 include 清單要涵蓋。
   - **模擬在 Web Worker** 以固定 30 TPS 推進（用累積時間，不用 setInterval 的漂移）；主執行緒每個 rAF 畫最新一次觀察資料，位置用前後兩個 tick 線性插值。
   - 開局畫面：選陣營（T／CT）、種子（預設隨機）、對手與隊友固定為陪練 Bot v3；「開始」後進入比賽；比賽結束顯示計分板（每人擊殺、死亡、金錢、回合比分）與「再來一場」。
   - **畫面資料來源**：玩家活著時一律 `observe(playerId)`；死亡後看隊友視角就是 `observe(隊友 id)`（可左右鍵切換）；只有「觀戰模式」（開局畫面的核取方塊，預設關、標示清楚）才讀引擎全狀態畫兩隊。Worker 只把 `ShooterObservation`（與觀戰用的全狀態快照）傳給主執行緒，主執行緒不持有引擎。
   - 畫面元素：地圖（牆、炸彈點 A／B 標示、出生區）、視錐迷霧（視錐外與視線外的區域壓暗，用射線扇形算可見區；視錐內被牆擋住的也要暗）、自己、隊友（含朝向、血條、武器圖示、持彈標記、致盲標記）、觀察資料裡的敵人、雷達紅點（畫在小地圖與主畫面都可）、`sounds`（主畫面邊緣或小地圖上的方向箭頭，近中遠三種大小，腳步／槍聲／落地／爆炸用不同圖示，顯示 0.5 秒）、煙霧（當下半徑的圓）、火圈、`projectiles`（小圓點）、掉落物、炸彈（掉落／已下包位置與倒數）、致盲時全畫面蓋白再依 `blindTicks` 淡出。
   - 操控（規格第八節）：WASD 以畫面方向移動（送 `moveDir`，放開送 `stop`）、滑鼠位置 → `aim`、左鍵按住 → `fire on`／放開 `fire off`、R 換彈、1／2／3 主副刀、4～7 道具槽（選中後左鍵按住蓄力、放開丟出，按住時間 0～1 秒線性對應 `power` 0～100，畫面要畫蓄力條與預估落點）、滾輪切槍、Shift 靜步、Ctrl 蹲、E 互動（在炸彈點持彈按住下包、貼近炸彈按住拆包、否則撿起）、B 購買選單、G 丟槍、Tab 按住顯示計分板、右鍵開鏡（狙擊）。
   - 鏡頭跟隨自己的選手，置中偏滑鼠方向少許；可選縮放。
   - HUD：血、甲、金錢、手上武器與彈藥、道具格（4 格）、投擲冷卻、炸彈狀態（持彈／下包中進度／已下包倒數／拆包進度）、回合編號與時間、比分、`canBuy` 提示、凍結倒數；小地圖（整張圖、隊友、雷達紅點、聲音箭頭、已下包位置）。
   - 購買選單：列出可買的武器、護甲、拆彈器、道具與價格，買不起或陣營不符灰掉，點擊送 `buy`；快捷鍵數字選購；凍結時自動開、`canBuy` 結束自動關。
   - 回合開始與結束的提示字（「第 N 回合」「T 勝：炸彈引爆」等）、半場換邊提示。
   - 除錯用的「全圖透視」開關只在觀戰模式有，玩家模式沒有。
4. 效能：主執行緒 60 fps；Worker 每 tick 工作量目前約 0.02 ms，不是瓶頸，不要為此改引擎。

## 四、規則

- `src/shooter/**`（除 runner.ts、human.ts）仍受確定性 eslint 規則；網頁端 `src/web/**` 不受，但不得把引擎狀態複製到主執行緒當作畫面來源（公平性靠這一條）。
- 畫面配色：單一主色加點綴色，不要摻多種色系；T 與 CT 用兩個對比色區分，其餘用灰階與主色（使用者的既定原則）。
- 不改經營層、不改軍團戰；不碰未追蹤的 docs 與 `scripts/_legion_*.ts`；不改步驟 1～3 的規則（第二節兩條除外）。
- lint 用 `npx eslint src bots test`；`npm run typecheck` 含 `tsconfig.web.json`。
- 完成條件：typecheck、lint、`npm test`（只允許既有 S16 失敗）、`npm run build:web` 成功、瀏覽器驗收通過。
