# 網頁 3D 觀戰實作說明（《軍團戰 美術風格 v2》的補充）

觀戰頁 `web/legion.html` 的對戰畫面可以在 2D 與 3D 之間切換（工具列「3D／2D」或 M 鍵，預設 3D）。3D 和 2D 吃同一份 worker 狀態流（`src/web/legion/protocol.ts`）與回放檔，引擎不知道畫面是 2D 還是 3D。美術依據是 `legion-art-trial` 分支的 `docs/軍團戰 美術風格 v2.md`；這份文件只記網頁 3D 的做法，以及和 v2 不一樣的地方。

## 一、檔案

| 檔案 | 內容 |
| --- | --- |
| `src/web/legion/view.ts` | 繪製器介面 `BattleView`：2D 的 `LegionRenderer` 與 3D 的 `Legion3DView` 都照它，`LegionScreen` 與玩家操控換一個繪製器就能用 |
| `src/web/legion/three/view3d.ts` | 3D 觀戰主體：鏡頭、狀態流、士兵與托盤、地面標示、資訊層（2D 畫布疊在上面） |
| `three/ground.ts` | 地形高度場、地表貼圖、水面、沙盤板剖面 |
| `three/city.ts` | 城牆、門洞拱券、馬道、橋、民房、殿堂、城樓、塔、牌坊、營帳、投石機 |
| `three/roofs.ts` | 中式屋頂（硬山、廡殿、歇山；凹曲面、起翹）、瓦壟與城磚貼圖 |
| `three/nature.ts` | 樹（苔蘚球闊葉樹、松、柳）、灌木、石塊；樹林裡有軍團時樹冠抖動半透明 |
| `three/units.ts` | 士兵（每種兵一個 InstancedMesh）、箭、貼地標示 |
| `three/siege.ts` | 城門門扇、雲梯、衝車、砲擊石彈、旗 |
| `three/palette.ts` | 色票（v2 第四節＋城內補充色） |

地圖的建物外觀記在 `LegionMap.decor`（選填，`src/legion/map.ts`）：民房朝向、殿堂、城樓、塔、農田、道路折線等。引擎與 `data.map` 都不讀它；沒有 decor 的地圖（大河谷、大草原、河谷）由建築格自動排成民房。

## 二、和 v2 不一樣的地方

| 項目 | v2 | 網頁 3D | 理由 |
| --- | --- | --- | --- |
| 地形一階高 | 0.30 格 | 城內 0.5 格；城外丘陵 0.95 格（平地仍是 0.5） | 0.30 時台地與長嶺幾乎看不出來；城外誇大才有自然起伏（使用者要求地形自然起伏、不要方塊） |
| 台地邊緣 | 平頂加 0.3 格陡坡 | 城外：格子高度模糊成平滑的高度場再加低頻起伏；城內、護城河：照格子保持平整與石砌的邊 | 同上 |
| 牆高 | 沒寫 | 牆頂比所在地面高 2.4 格（引擎是 3 階，用在射程與視線） | 3 階 × 0.3＝0.9 格，比人只高半個頭，看不出城牆 |
| 主光 | 西北上方 | 一樣從西北，仰角約 41° | 影子拉長，建物與士兵看起來貼地 |
| 鏡頭水平轉角 | 中景、近景 ±35° | 一樣；全圖固定北朝上 | — |
| 移軸景深、SSAO | 中景、近景要有 | 還沒做 | 先求畫面正確；之後再加 |
| 士兵造型 | 第五節的尺寸與造型 | 尺寸照 v2，造型是簡單的方塊人（使用者說人物可以先隨便做） | — |
| 隱蔽 | 樹冠透明度 .4 | 樹林裡的軍團附近樹冠用抖動挖洞（隱蔽中挖 60%、沒隱蔽 45%） | 半透明的樹要排序，抖動不用 |
| 低多邊形畫風 | — | 試做過，使用者看過後決定先拿掉 | 若要再做，先確認想要的樣子 |

## 三、畫面規則

- 高度：地面層的人站在地形、馬道石階或橋面上；牆頂層站在牆頂；爬雲梯中的人沿梯子內插。
- 雲梯：架設中從平放在地上（梯頂朝外）慢慢立起；推倒時往外倒。
- 衝車：引擎把衝車放在推車那團正前方（規格書 18.5）。畫面上把那團編號最小的 9 個人移到車尾與車側的推車位置（離原位兩格內），看起來是人在推車。
- 托盤、範圍（槍林扇形、盾兵掩護、齊射落點、衝刺路線、選取框、旗圈、砲擊落點）貼在地面上，會被建物擋住；軍團旗標、特效文字、倒數、城門血量畫在上層 2D 畫布，固定大小。
- 玩家指揮：選取、框選、右鍵移動都和 2D 一樣；按住 Q 的瞄準預覽（衝刺路線與會被擋下的位置、齊射射程與落點、槍林扇形）貼在地面上。

## 四、開發時檢查畫面

- 開發模式下主控台有 `__v3d.view`，可以直接設鏡頭（`cam.x`、`cam.y`、`cam.scale`、`yaw`、`tilt`）。
- 瀏覽器分頁在背景時 `requestAnimationFrame` 不跑：手動呼叫 `view.draw(...)`，把 WebGL 畫布與資訊層畫布合成一張圖再看。
