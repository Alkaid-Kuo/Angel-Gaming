# 基準 BOT 後續訓練與平衡研究建議

2026-10-26。依使用者提供的訓練回饋、v1.68 固定驗收與凍結 0.3.2 引擎整理。現階段不調整正式數值，不自動開始下一輪訓練；每輪時限由使用者公告。

## 判讀

目前可以確認「這套控制器用盾弓與全輕步兵取得較好結果」，不能直接推論其他兵種弱。v1.68 正式驗收的保留池勝率為殲滅 73.3%、佔點 67.1%，殲滅戰 T0 有兩組不足 95%；可見佔點開發成績高，也還不是對未知策略普遍成立的支配打法。下一輪同時追求勝率與平衡研究時，必須分開資料與成果。

## 兩條工作線

| 工作線 | 固定條件 | 目標與交付 |
| --- | --- | --- |
| BOT 改善 | 引擎、兵種數值與規則固定 | 改善殲滅弱項、擴大佔點泛化，交付較強且可靠的新版及比較證據 |
| 平衡研究 | 每組比較固定控制器版本、預算上限、種子與座位 | 補齊七兵種與混編的操作，再辨別機制／數值問題；假設、對照組與結果分開記錄 |

可以由同一 Agent 分階段執行，但不能同時改 AI、價格與得分規則，再把勝率變化歸因給其中一項。先凍結現在 v1.68 作試玩和回歸錨點，後續另存新版；不覆寫已交付檔案與既有驗收紀錄。

## 第一階段：補齊操作，而非直接削弱強勢兵種

統一導航、觀察與測試框架，每兵種保留合理的特化控制。劍士、輕騎、重騎目前探索不足，應先補完接敵、側擊、脫離與再衝鋒，不拿成熟盾弓對比只會直衝的騎兵。

| 兵種 | 至少要驗證的控制能力 |
| --- | --- |
| 長槍 | 提前架陣、朝向、移動與重新架設，避免一直停在錯誤位置 |
| 劍士 | 接敵、側包與突擊，不盲目頂著架好的槍陣 |
| 盾兵 | 掩護朝向／位置、舉盾與盾牆時機、轉場代價 |
| 弓兵 | 射程與退位、集火、掩護內站位及接敵處理 |
| 輕步 | 分路、反弓、旗點輪轉及避免無效追擊 |
| 輕騎 | 追截輕步、突擊弓兵、脫離再衝，避免正面撞槍 |
| 重騎 | 衝鋒距離／時機、側背突破、接觸後脫離與再衝 |

現行相剋表讓輕騎與重騎對輕步／弓兵有加成，輕騎也更快，因此「成熟輕騎能否懲罰全輕步搶旗」是重要的反證測試；這不是預先保證騎兵一定能克制。純盾或純槍不必單獨勝率高，支援兵種要看加入混編後的邊際價值。

## 第二階段：純兵與混編覆蓋

1. 七兵種純編成先跑 7×7 有向對陣矩陣，兩種模式、共同開發種子。非鏡像組等同交換座位配對；同款鏡像用來查側別差，不重複把同一次鏡像結果當獨立樣本。每個有向組合用 N 個種子，兩模式共 98N 場；N=10 的 980 場只作初篩，不據此宣告平衡。
2. 都使用相同點數上限，同時記錄實際花費與未用點數。不可用相同「團數」代替相同預算；兵種價格離散，不能假裝每份陣容剛好花滿。
3. 再掃兩兵種混編：按點數比例做 25／50／75% 初篩，先對代表性戰術族群測試，不讓全部組合一次造成場數爆炸。把高協同、疑似支配與明顯弱項的組合列入深入控制開發。
4. 新增自建對手寫在自己的 experiments/controllers 等非保護目錄，使用自己的程式；官方競技場對手仍是黑盒，不讀取歷史選手或私有對手來源。自建控制器對戰資料與官方訓練池資料分開。
5. 初篩後，把重要比較擴大到更多未用過的開發種子與雙座位，至少報告區間／不確定性。以種子作配對單位，保留座位間的相關性，不能把兩個座位當完全獨立樣本。

## 第三階段：針對機制做對照實驗

### 槍陣與盾牆

回饋中的 29%→82% 同時改了槍陣寬度與架設時機。做四個版本：原寬度／原時機、只加寬、只提早、兩者都改；其餘條件保持一致。盾牆提早後 82%→26% 也先拆解定位、轉場與接敵時機，不直接歸因盾兵數值弱。

### 輕步兵與佔點

程式確認：未潰逃的活兵進圈即算該方存在，佔領進度不隨人數增加，敵人進圈會暫停持有者得分。應量測「殘兵能干擾多久、清除它需要多少兵力／時間、損失多少分數、轉場成本」，再看成熟反輕步策略是否有效，不能只由進圈邏輯推論失衡。

### 盾弓掩護

85／90% 是掩護區的遠程減傷，須在盾兵後方矩形內、攻擊來自正面角度；多盾不疊加，取最好的一團。先測保持掩護、轉向、側射、騎兵突破與逼迫轉場。若成熟反制仍無效，再於獨立研究副本逐一調整範圍、角度或減傷；不把弓兵傷害當唯一嫌疑。

### 方位差與避戰

53%／89% 的側別差要先排除樣本與種子差異，再拆為控制器方向硬編碼、河谷地形與起始站位問題。做鏡像控制器／鏡像部署及配對種子測試，新增測試地圖如有需要只在研究副本進行。殲滅戰時間到比較戰果，領先後避戰是目前規則誘因；若它是你不想要的玩法，再另訂規則候選，不能把它全算成兵種數值問題。

## 資料切分與判準

- 開發種子分成探索集與不反覆調參的驗證集，皆在允許的開發範圍；保留池仍由裁判在新版凍結後正式驗收，不能拿來當日常調參回饋。
- 記錄引擎／控制器雜湊、配置、實花費、種子與 rngBase、座位、勝敗平、損失點數、旗點控制時間、被拒指令與嚴重錯誤；原始資料可重現。
- 不要求每種兵全局勝率都等於 50%。健康相剋可以非傳遞；重點是支配策略有沒有合理反制、每兵種有沒有可用定位、結果是否跨種子與側別成立。
- 機制已確認、策略有效、數值失衡是三種不同結論。未測過的格子標示「未測」，控制器尚未成熟標示「控制未成熟」，不要當成弱兵種的負證據。
