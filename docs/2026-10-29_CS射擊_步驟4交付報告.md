## 四、與任務書的出入、我自己定的事（逐條）

### 引擎與驅動層
1. **開鏡時用開鏡視錐夾**：任務書寫「fov／2」，開鏡時視錐是 30°，就夾到 ±15°（投出時才解除開鏡）。
2. **引擎版本升到 0.4.0**：投擲規則變了，0.3.0 的回放投擲結果可能不同。
3. 人類指令在決策 tick 排在 Bot 之後套用（Bot 先看同一份觀察資料再下指令），回放也照這個順序記錄。
4. 既有測試與驗收情境 G3／G4 的投擲者改成面向目標（第二節）。

### 操控
5. **道具「選中」只是畫面狀態**：引擎沒有「手持道具」（規格：丟雷不需切換到道具槽），選了 4～7 之後手上仍是槍，只是左鍵改成蓄力投擲；投出或再按同一格、1／2／3、滾輪都會收起。
6. **放開 E 中斷下包／拆包**：引擎沒有「取消」指令，中斷的方式是送 `moveDir`＋`stop`（移動會中斷動作，同 CS 移動中斷下包）。
7. **蹲另外綁 C**：Ctrl 照規格可用，但瀏覽器的 Ctrl+W 會直接關分頁、無法攔截，建議用 C。Ctrl 組合鍵（除了 Ctrl 本身）一律不攔，以免擋到瀏覽器快捷鍵。
8. **瞄準點約每 30 ms 送一次**（約每 tick 一次），滑鼠沒動就不送，避免回放膨脹。
9. **Esc 暫停**：單人對 9 隻 Bot，暫停不影響公平；暫停時不送指令。切到別的分頁（`visibilitychange`）也自動暫停。聯賽模式（步驟 8）要拿掉。
10. 購買選單快捷鍵只編給本隊能買的品項（1～9、0、-、=）；選單開著時這些鍵優先給購買。

### 畫面
11. **投擲冷卻從觀察資料推**：觀察資料沒有 `throwCd`，HUD 用「自己的道具在非凍結時間少了一顆」起算 0.5 秒，回合交接歸零（引擎也是）。
12. **擊殺訊息（右上）**：任務書沒寫；CS 的公開資訊（誰殺誰、用什麼），不含位置。計分板的敵人金錢在比賽中不給（`—`），比賽結束才顯示。
13. **雷達點用敵方隊伍色的空心圈**，不是紅色（配色原則：只有 T 琥珀／CT 天藍兩個對比色）；火用橘色漸層（與 T 同色系）。
14. **看得見但在畫面外的敵人**：畫面邊緣畫一個指向它的三角形。地圖的長對線（B 通道、A 長、中路）超過預設畫面範圍，不加這個就會「被看不見的人打死」；資料仍是 `enemies`。
15. 鏡頭：自己活著時往滑鼠方向偏 45%（滑鼠移到畫面邊緣可以多看約 1／4 個畫面）；看隊友或觀戰時置中。縮放 6 段（10～36 px／格），玩家預設 18。
16. 迷霧射線每度 2 條、浮點 DDA；自己身邊 0.7 格不壓暗（只是讓自己的圖示不被蓋住，不代表看得見背後）。迷霧只是陰影，誰在 `enemies` 由引擎的整數視線決定，牆角附近兩者可能差一點點。
17. **聲音只有畫面、沒有音效**：任務書只要求箭頭。Worker 在每個決策 tick 收一次聲音（觀察資料的聲音視窗是 3 tick），不重複不漏；換觀看對象時清掉舊箭頭。
18. 致盲：`blindTicks / 24` 的白色不透明度（最後 0.8 秒淡出）。致盲時小地圖仍畫隊友（觀察資料本來就給）。
19. 全隊陣亡：畫面停在最後看的隊友位置、全暗，提示「全隊陣亡・等待下一回合」。
20. 觀戰模式：跟隨一名選手（← →），畫兩隊全狀態；迷霧是被跟隨者的視錐，X 關掉迷霧並改用全狀態畫煙、火、道具、掉落物（全圖透視）；速度 0.5～8 倍。
21. 除錯：開發模式或網址帶 `?debug` 時有 `window.__sg`（只有主執行緒本來就有的 frame，沒有引擎）；`?auto=T|CT|spectate&seed=N` 直接開局。
22. 選 CT＝玩家 5（上半場 CT 那一組），下半場換成 T。

## 五、給使用者的試玩指南

### 啟動
```
npm run web
```
開 `http://localhost:5173/web/shooter.html`（5173 被占用時 vite 會改用下一個埠，看終端機顯示）。或先 `npm run build:web`，再 `npm run serve` 開 `http://localhost:8000/web/shooter.html`。

開局選 T 或 CT、種子（預設隨機），按「開始」。勾「觀戰模式」是看 10 隻陪練 Bot 互打（除錯用，不是玩家視角）。

### 按鍵
| 按鍵 | 動作 |
|---|---|
| W A S D | 移動（畫面方向；畫面上方是北） |
| 滑鼠 | 瞄準（轉身有上限 720°／秒，滑鼠甩太快角色會慢慢轉過去） |
| 左鍵 | 開火（自動武器按住連射） |
| 右鍵 | 開鏡（狙擊槍；視錐縮成 30°） |
| R | 換彈 |
| 1／2／3、滾輪 | 主武器／副武器／刀 |
| 4～7 | 選道具 → 按住左鍵蓄力（0～1 秒＝力道 0～100），放開往滑鼠方向丟；有預估落點虛線 |
| Shift（按住） | 靜步：無聲、變慢 |
| C 或 Ctrl（按住） | 蹲 |
| E | 在 A／B 點帶著炸彈按住＝下包（3.2 秒）；CT 貼著炸彈按住＝拆包（10 秒，有拆彈器 5 秒）；其他時候撿腳邊的槍或炸彈 |
| B | 購買選單（凍結時自動開；數字鍵快速購買） |
| G | 丟槍 |
| Tab（按住） | 計分板 |
| - ／ = | 縮放（長對線看不到時縮小） |
| Esc | 暫停 |
| ← →／滑鼠左右鍵 | 陣亡後切換隊友視角 |

畫面怎麼看：亮的扇形是你的視野（牆、煙會擋），扇形外的敵人一律不畫；小地圖上的空心圈是隊友正看到的敵人；角色身邊的白色小箭頭是聽到的聲音（大＝近、小＝遠，灰色是隊友），畫面邊緣的三角形是看得見但在畫面外的敵人。

### 已知問題
- 地圖長對線比畫面長：預設縮放下看得見的敵人可能在畫面外（只有邊緣三角形與小地圖點），要按 `-` 縮小。
- 沒有音效，聲音只用畫面箭頭表示。
- 陪練 Bot 沒有戰術：CT 的閃光常閃到隊友、T 常一起擠在同一條路；角色之間不碰撞（可以穿過隊友）。
- Ctrl+W 會關掉分頁（瀏覽器限制），蹲請用 C。
- 打完的比賽沒有提供回放下載或重看（Worker 有錄，介面還沒接）。
- 迷霧是浮點近似：牆角附近陰影邊緣與引擎的整數視線可能差一點點（誰看得見以引擎為準）。

### 步驟 5 待審清單（彙整規格第十四節、步驟 3 報告與本步驟）
1. 視角 100°、轉身 720°／秒、腳步聲 20 格。
2. 爆頭替代（命中圓心加成）要不要。
3. 12:12 加時規則。
4. 箱子要不要做成「擋移動不擋視線」的半高物。
5. 角色之間要不要碰撞。
6. 道具：火圈要不要被牆擋；自己被自己的手雷、火全額傷害要不要改成 30%；閃光致盲時要不要保留聲音；道具死亡要不要掉落一顆。
7. 陪練 Bot：CT 的閃光常閃到隊友；CT 偏窮。
8. （本步驟新增）人類指令每 tick 套用、Bot 每 3 tick：人類的反應上限比 Bot 高，試玩後看要不要拉齊。
9. （本步驟新增）預設縮放與鏡頭偏移：長對線要不要自動縮放，或給狙擊鏡更大的視距。
10. （本步驟新增）擊殺訊息要不要保留（會透露敵人用什麼槍）；雷達點的畫法。
11. （本步驟新增）暫停功能在聯賽或對戰模式要拿掉；打完的比賽要不要提供回放下載／重看。
