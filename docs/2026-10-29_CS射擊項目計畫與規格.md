## 一、定位與已定事項

Angel Gaming 的第二個電競項目。經營層不變（戰隊、選手、聯賽、下注），只是比賽內容從軍團戰換成 5v5 攻防射擊。

| 事項 | 決定 |
|---|---|
| 技術 | TypeScript 無頭模擬＋Canvas 2D，沿用軍團戰的確定性整數數學、選手沙盒、回放、Worker、觀戰頁 |
| 視角 | 2D 俯視，滑鼠瞄準 |
| 規則 | 參照 CS：攻方（T）帶炸彈打 A／B 點，守方（CT）防守；不重生、回合制、半場換邊；有經濟（買槍）與道具 |
| 地圖 | 赤岩鎮（v0.5 起預設，原創格局）；沙城（參照 Dust2 路線結構）只供引擎測試與驗收 |
| 順序 | **先把遊戲做到可玩（含經濟、道具、玩家操控），規則凍結後才開始做基準 Bot** |
| 選手 | 一隻基準 Bot 讀「屬性包」衍生大量選手；流派＝角色 |
| 閘道 | 經營層只送雙方名單與種子、只收勝負與回合比分；名單人數由各項目的內容包宣告，經營核心不寫死 |
| 公平 | Bot 與玩家吃同一套視野、聲音、轉身速度限制；**沒有全知 Bot** |

## 二、視野、聲音與公平規則（最重要）

這一節是本項目與「無敵 Bot」劃清界線的地方，引擎層強制，不靠 Bot 自律。

### 視野
- 每個人有朝向與**視錐**：水平視角 100°，視錐外一律看不見，包括背後 0.5 格的人。
- 視錐內還要通過**視線**（格子射線，牆、煙霧會擋）。煙霧擋：敵我判定、雷達、掉落物與炸彈可見、閃光的視線；**不擋**子彈、聲音、移動（v0.3）。
- 視距（v0.5）：不開鏡 30 格、開鏡 60 格；長對線要開鏡才能對狙。
- 狙擊鏡：開鏡時視錐縮到 30°、移動速度減半；不開鏡時狙擊槍極不準。
- 蹲下：散佈 ×0.7、速度 34%、沒有腳步聲；v0.5 起蹲在矮牆後 2 格內，矮牆擋住雙方視線與子彈（自己也只能從側面看出去）。被打中的模型大小不變。
- 隊伍共享的只有「雷達」：隊友位置，以及隊友**此刻看見**的敵人座標點（不含朝向與血量），對應 CS 的小地圖紅點。

### 角色碰撞（v1.0）
- 每個人是半徑 `bodyRadius`（300，0.3 格）的圓；**所有活著的人互相碰撞**，不分敵我，任兩個活人圓心距離不得小於 2 × `bodyRadius`。死人不擋；下包中、拆包中的人也是實體。
- 每 tick 移動時先照 `slideAxis` 對牆滑動，再對其他活人做同樣的兩軸分開檢查：會重疊的那一軸退到最遠不重疊的位置（不推人、不彈開）。斜著撞上別人時另一軸照走，會貼著對方的圓周滑開。
- 處理順序確定且不偏袒：起點 `tick % 10` 輪轉，每 10 tick 順向、逆向交替；20 tick 一個週期內任兩人誰先走恰好各半。
- 凍結時間夾回出生區之後再檢查一次，和人重疊就退回該 tick 的原位。出生點任兩點距離 ≥ 2 × `bodyRadius`（兩張圖有測試）。
- 尋路不知道人在哪：被人擋住時沿用卡住重新尋路（連續 15 tick 幾乎沒前進），繞人是選手程式的事。

### 友軍傷害（v0.2）
- 開啟。子彈（含霰彈每顆、刀）打到第一個人就停，**不分敵我**，所以隊友會擋子彈。
- 打到隊友只造成 **30%** 傷害（`FRIENDLY_FIRE_PCT = 30`），之後照常算護甲。
- 隊殺不算擊殺數，擊殺者 −300（第六節）。道具傷害接同一條規則：手雷、燃燒打到隊友 30%（第七節）。

### 聲音
- 跑步腳步：半徑 20 格內可聽見。靜步（Shift）無聲。
- 槍聲：全圖可聽見（狙擊、步槍）或半徑 60 格（手槍、衝鋒槍）。
- 下包、拆包、換彈、丟雷落地、腳步都是事件，帶**粗略方向（±15°）與距離等級（近／中／遠）**，不給精確座標。
- 玩家聽到的聲音畫在雷達上當方向指示；Bot 收到同一批事件，不多不少。
- **閃光致盲時聲音保留**（v1.0 定案）：致盲只清空視覺類資料（見第七節），`sounds` 照給。

### 轉身與反應
- 所有人轉身速度上限 720°／秒（180° 要 0.25 秒），玩家滑鼠超速也會被夾住。
- **引擎強制：Bot 指令延遲 ≥ 5 tick（167 毫秒）**（v1.0）。Bot 在 tick t 回傳的指令從 tick t + `reactionTicks` 起才生效（驅動層排隊，`ShooterMatch` 的指令介面不變）；`reactionTicks` 依選手設定，下限 `MIN_REACTION_TICKS = 5`，傳更小的值夾到 5，屬性「反應」只能讓它更慢。選手從 `rules.reactionTicks` 知道自己的延遲。回合交接時還沒生效的指令作廢。
- 人類玩家不延遲（本來就有生理反應時間），指令每 tick 套用；Bot 每 3 tick 決策（v1.0 定案維持：聯賽是 Bot 對 Bot，人類只在試玩出現）。
- Bot 的瞄準誤差隨距離、移動、連射遞增，與玩家的散佈同一套公式；Bot 的「準」來自更快收斂，不是跳過散佈。

### 不允許 Bot 拿到的資訊
敵人的位置（視野外）、朝向、血量、金錢、買了什麼、炸彈在誰身上（除非看見）、對方的指令。選手 API 的觀察資料裡**根本沒有**這些欄位，所以外部選手也拿不到。

## 三、回合與賽制（參照 CS2）

| 項目 | 數值（v1.0 定案） |

加時細則（v1.0）：
- 半場編號 `half`：正規 1、2；加時每個半場遞增（第一段 3、4，第二段 5、6…）。`overtime`：0 正規，1 起第幾段。回合編號連續遞增（第 25 回合起是加時）。
- 陣營：上半場玩家 0～4 是 T；下半場換邊；**每段加時開始不換邊**（延續上一個半場），段內 3 回合換邊。即半場 1 T、2 CT、3 CT、4 T、5 T、6 CT…（以玩家 0～4 為準）。
- 結束判定：段內以「該段開始時的比分」（雙方相同）為基準，某隊在段內拿到 4 勝就結束；該段打滿 6 回合仍平手就進下一段；第 4 段打滿仍平手 `winner = null`。
- 測試用選項 `overtime: false` 保留舊行為（正規平手直接平手），只給短賽制測試用；聯賽一律加時。

經營層視角：一張請求單＝一場比賽（兩隊各 5 人），成績單＝勝方＋每回合一筆（引擎的 `RoundRecord`，v1.0 定案）；顯示用的 label（「上半場 7:5」「加時 1」）由經營層在步驟 8 組。

## 七、道具（v0.3，v1.0 定案）

| 道具 | 價格 | 數量上限 | 生效 | 效果 |
|---|---|---|---|---|
| 閃光 | 200 | 2 | 投出 1.5 秒 | 15 格內且有視線者致盲（含隊友與自己）；正對 2.0 秒、側向 1.0 秒、背對 0.3 秒，再乘距離係數 |
| 煙霧 | 300 | 1 | 投出 1.5 秒 | 1 秒內半徑從 0 長到 3 格，持續 18 秒；擋視線不擋子彈；撲滅重疊的火 |

- 道具總格 4 個；閃光占 2 格以內。死亡**不掉落**道具（維持步驟 2）。

### 投擲
- 指令 `throw { grenade, deg, power }`：要帶著該道具（不需切換到道具槽）、不在凍結時間、不在投擲冷卻內；投出後從背包移除。方向夾在視錐內（v0.4）：與朝向夾角超過 fov／2 就夾到視錐邊界。
- `power` 0～100 線性對應投擲距離 0～25 格（`maxThrowRange`）。
- 2D 直線飛行，速度 `flySpeed`（900 units／秒 ≈ 17 格／秒）；不模擬拋物線高度，飛行中不碰人。
- 碰牆**反彈一次**：分 x、y 軸移動，撞到的軸把方向分量反號（軸對齊牆面的法線鏡射，整數運算），剩餘距離繼續；第二次碰牆就停；走完距離就停（落地）。
- 投擲與開火互斥：投出時停火、取消下包／拆包；投擲後 0.5 秒（`throwCooldownTicks`）內不能再投、也不能開火。
- 生效時機：閃光、煙霧、手雷＝投出後 `fuseTicks`（1.5 秒）在當下位置生效（可能還在飛）；燃燒＝落地或第二次碰牆時立刻生效，飛滿 `fuseTicks`（1.0 秒）也在空中生效。
- 聲音：落地或反彈發 `grenadeLand`（15 格）；手雷與閃光生效發 `explosion`（60 格）；煙霧與燃燒生效發 `grenadeLand`。投擲者自己不收自己道具的聲音（同槍聲、腳步）。

### 煙霧
- 生效後 1 秒（`smokeBloomTicks`）內半徑從 0 線性長到 3 格，從生效起算 18 秒後消失。
- 擋視線：見第二節。觀察資料的 `effects` 給煙霧當下的實際半徑。
- 撲滅火：煙霧生效中（含擴散中）與火圈重疊（兩圓心距 < 兩半徑和）時，該火立即消失；燃燒落點的火圈與既有煙霧重疊就不點燃。

### 閃光
- 生效時對**所有活著的人（含隊友與自己）**：距離 ≤ 15 格、且從該人到爆點有視線（牆與煙霧都擋）才致盲。
- 基礎值依爆點方向與朝向的夾角：≤ 60° 正對 2.0 秒、≤ 120° 側向 1.0 秒、其餘背對 0.3 秒；再乘距離係數 `1 − d／(2R)`（貼臉 100%、15 格外緣 50%），取整數 tick。
- `blindTicks` 取較大值，不累加。致盲期間觀察資料的 enemies、radar、effects、items、projectiles 都是空的，自己與隊友資料照給；仍可移動、開火、投擲。

### 手雷
- 對半徑 3.5 格內所有活著的人（含隊友與自己）：傷害 `98 × (1 − d／R)`（取整）；有視線才算（牆擋、煙霧不擋）。
- 護甲吸收 50%（以剩餘甲值為上限）並扣同量甲值；隊友 30%（先打折再算護甲）；自己全額（v1.0 定案，與 CS 一致）。

### 燃燒瓶／燃燒彈
- 半徑 3 格的火圈持續 7 秒；點火後每 0.2 秒對圈內活著的人扣 8 點（40／秒，**不吃護甲**）；隊友 30%、自己全額。
- 火圈被牆擋（v0.5）：只燒得到半徑內、跟火焰中心之間沒有牆的格子（矮牆不擋火）。

### 擊殺與經濟
- 道具擊殺歸投擲者：獎金 300（`grenadeKillReward`）；炸死／燒死隊友 −300（隊殺）；炸死／燒死自己 −300、不算擊殺。

### 回合交接
- 進入下一回合時清除所有還沒生效的道具、煙霧、火；致盲與投擲冷卻歸零。回合結束後的 5 秒展示時間內效果照常。

## 八、玩家操控與畫面（v0.4，步驟 4 實作）

入口 `web/shooter.html`（程式在 `src/web/shooter/`）。開局選陣營（T＝玩家 0、CT＝玩家 5；半場換邊後陣營互換）與種子，另外 9 個位子固定是陪練 Bot（v1.0 時為 v5）。暫停只在試玩網頁有，無頭比賽與聯賽沒有暫停（v1.0 定案）。

### 輸入頻率與公平
- 人類的指令經 `ShooterHumanController`（`src/shooter/human.ts`）**每個 tick 套用**，不必等決策 tick、沒有反應延遲；Bot 仍每 3 tick 決策、指令延遲 5 tick 生效（v1.0）。回放把所有指令按實際套用的 tick 記錄，重播雜湊相同。
- 轉身上限、散佈、冷卻、投擲夾視錐對人類一視同仁，不另開後門。
- 模擬在 Web Worker 以固定 30 TPS 推進（累積時間）；主執行緒每個畫面畫最新的觀察資料，位置在前後兩個 tick 之間線性插值。

### 畫面資料來源（公平靠這一條）
- 玩家活著：只畫 `observe(自己)`。陣亡：畫 `observe(隊友)`（← → 或滑鼠左右鍵切換）；全隊陣亡就是全暗等下一回合。
- Worker 只把觀察資料與計分板的公開資訊（每人擊殺、死亡、存活；敵人金錢在比賽中不給）、擊殺訊息傳給主執行緒，主執行緒不持有引擎。
- 只有開局勾選「觀戰模式」（不參賽，10 隻陪練 Bot 互打）才另送引擎全狀態並畫兩隊；「全圖透視」（X）只在觀戰模式有。

### 畫面元素
- 地圖（牆、A／B 點、兩隊出生區、區域名）、**視錐迷霧**（從所看選手的位置對視錐打射線，遇牆或看得見的煙霧就停；扇形外全部壓暗）。
- 自己與隊友（朝向、血條、武器、持彈、下包／拆包、致盲標記）、觀察資料裡的敵人（看得見但在畫面外時，畫面邊緣有指向它的三角形）、雷達點（隊友看見、自己沒看見的敵人：空心圈＋「?」）。
- 聲音：所看選手周圍的方向箭頭，近／中／遠三種大小與距離；腳步＝兩點、槍聲＝放射線、換彈＝弧、落地＝圓、爆炸＝星、下包／拆包／嗶聲＝方塊；隊友的聲音灰色。顯示 0.5 秒淡出。小地圖上也畫。
- 煙霧（當下半徑）、火、看得見的道具（小點＋字）、掉落物、炸彈（掉落／已下包位置與倒數）、致盲時全畫面蓋白、最後 0.8 秒淡出。
- 配色：灰階為底，T 琥珀、CT 天藍兩個對比色；不另加其他色系。

### HUD
- 上方：T／CT 比分與存活人數、時間（凍結倒數／回合時間／炸彈倒數）、回合與半場（加時顯示「加時 N・上／下半場」，v1.0）；提示列（凍結倒數、可購買、持彈下包、拆包）。
- 左下：血、甲（拆彈器）、金錢。右下：彈藥（換彈中）、開鏡／靜步／蹲，武器欄 1 主武器、2 手槍、3 刀、4 道具（列出種類、選中的加底線）、5 炸彈（沒有的格子變暗，手上的那格反白），投擲冷卻條（v0.5）。
- 戰鬥回饋（v0.5，資料來自觀察資料 `me.shots`／`me.hurt`／`enemies[].firing`）：自己的子彈彈道（0.14 秒淡出）、打中時準心出現斜角命中標記（擊殺加粗、敵方隊伍色）、受傷時自己周圍出現指向傷害來源的弧、看得見的敵人開火時槍口火光。
- 中下：炸彈狀態（持彈／隊友下包中／下包進度／已下包在哪一點與倒數／拆包進度）。右上小地圖：整張圖、隊友、看得見的敵人、雷達點、聲音箭頭、已下包或看得見的掉落炸彈；擊殺訊息在小地圖下方（v1.0 定案保留：只在人類畫面，選手觀察資料不含擊殺訊息）。

## 九、選手 API（1.0，已凍結）

選手程式只依賴 `src/shooter/api.ts`；**完整型別以該檔為準**，這裡列欄位清單。版本：`SHOOTER_API_VERSION = '1.0'`（開局資料 `rules.apiVersion`），引擎 `SHOOTER_ENGINE_VERSION = '1.0.0'`。

### 選手模組
- `declare()`：名稱、版本、流派、旋鈕定義。
- `init(data, helpers)`：開局一次（整場，換邊不重呼叫）；1 秒上限，超時整場閒置。
- `decide(obs)`：每 3 tick 一次（死亡與凍結時間也呼叫）；50 ms 硬上限，超時當該次無指令，同一回合連續超時 10 次該回合閒置。回傳的指令 **5 tick 後才生效**（`rules.reactionTicks`）。
- `helpers`：`random()`（確定性亂數）、`isSolid(cx, cy)`（牆或矮牆）、`clearLine(ax, ay, bx, by)`（站姿視線，不含煙霧）、`dist`、`angleTo`、`offset`、`regionsAt`。

### 開局資料 `ShooterInitData`
- `playerId`（0～9；0～4 上半場 T）、`startTeam`、`slot`（隊內序號 0～4）、`teammateIds`、`enemyIds`、`knobs`、`attributes`（瞄準、反應、警覺、侵略、紀律、走位，各 0～100；基準 Bot 讀，外部選手可忽略）。
- `rules`：`apiVersion`、`ticksPerSecond`、`decisionInterval`、`reactionTicks`、`unit`、`teamSize`、`fovDeg`、`scopedFovDeg`、`viewRange`、`scopedViewRange`、`lowCoverRange`、`turnDegPerSec`、`bodyRadius`、`footstepRange`、`friendlyFirePct`、`roundsPerHalf`、`winRounds`、`overtime`（`{ roundsPerHalf, winRounds, maxBlocks }` 或 `false`）、`freezeTicks`、`buyTicks`、`roundTicks`、`bombTicks`、`plantTicks`、`defuseTicks`、`defuseKitTicks`、`startHp`、`maxArmor`、`armorPrice`、`ammoPrice`、`kitPrice`、`grenadeSlots`、`grenadeRules`（投擲距離、飛行速度、冷卻、煙霧擴散、閃光參數、HE 護甲比例、燃燒結算間隔）、`economy`（起始金錢、`overtimeMoney`、上限、各種回合獎金、連敗階梯、下包敗補償、下包／拆包獎金、道具擊殺獎金、隊殺罰款）。
- `map`：尺寸、`solid`（0 可走、1 牆、2 矮牆）、`sites`、`spawnZones`、`spawns`、`regions`。`weapons`、`grenades`：武器表與道具表。

### 觀察資料 `ShooterObservation`
- `tick`、`round`（`number`、`half`、`overtime`、`phase`、`phaseTicksLeft`、`scoreT`、`scoreCT`、`canBuy`、`ended`）。
- `me`：`id`、`team`、`alive`、位置、`facing`、`hp`、`money`、`loadout`（主副武器、道具、甲、拆彈器）、`weapon`、彈匣與備彈、`reloadTicksLeft`、`spread`、`scoped`、`walking`、`crouching`、`hasBomb`、`blindTicks`、`plantTicks`、`defuseTicks`、`vx`／`vy`、`shots`（自己的子彈）、`hurt`（受傷方向）。
- `teammates`：位置、朝向、血、金錢、武器、持彈、下包／拆包、致盲、開火。
- `enemies`：**自己視錐內且有視線**的敵人：位置、朝向、武器、蹲、下包／拆包、持彈、開火；沒有血量與金錢。
- `radar`（隊友此刻看見的敵人座標點）、`tracers`（隊友的、或開槍當下看得見的敵人的子彈）、`sounds`（種類、量化方向、距離等級、槍種、是否確定是隊友）、`bomb`（依觀察者的隊伍與視野）、`effects`（看得見的煙霧與火）、`items`（看得見的掉落物）、`projectiles`（看得見的還沒生效的道具）、`chat`（隊內喊話）、`enemiesAlive`。
- 沒有：視野外敵人的任何欄位、敵人血量與金錢、擊殺訊息、對方的指令。致盲時 `enemies`、`radar`、`effects`、`items`、`projectiles` 為空，`sounds` 照給。

### 指令 `ShooterCommand`
- `move { x, y }`（引擎尋路）、`moveDir { deg }`、`stop`、`aim { x, y }`、`fire { on }`、`switch { slot }`、`reload`、`walk { on }`、`crouch { on }`、`scope { on }`、`plant`、`defuse`、`pickup`、`drop { bomb? }`、`buy { items }`（武器、道具、`armor`、`kit`、`ammo`）、`throw { grenade, deg, power }`、`say { text }`。
- 每次最多 32 道、`buy` 最多 16 項、喊話最多 120 字；不合法的指令與項目略過。

### 凍結後變更流程（v1.0）
- 規則與選手 API 在基準 Bot 階段（步驟 6～7）**不得改**。
- 真要改：升 `SHOOTER_API_VERSION`（欄位或語意變動）與 `SHOOTER_ENGINE_VERSION`、在本文件寫修訂紀錄、重跑全部驗收（`npm test`、`shooter batch` 兩張圖）與強度表（步驟 7 起）。
- 只改畫面、CLI、測試、陪練 Bot 不算規則變更，但不得讓選手拿到更多資訊。

## 十一、基準 Bot 與選手衍生（步驟 6～7，規則凍結後）

- 四層：感知（視錐、記憶、聲音）、導航（A*＋掩體與對線點標註）、戰鬥（反應、瞄準收斂、探頭、撤退）、戰術。
- 戰術層用 CS 的語言：守方預設站位與輪轉、攻方控圖再打點或直衝、聽槍聲回防、下包後守包位、殘局換血、經濟（全買／半買／eco 的隊內決策）、道具（進點前煙閃、守點燃燒彈封路）。
- 五角色＝流派：突破手、狙擊手、支援（道具手）、錨點、游擊。版本＝屬性成長，個人習慣＝小偏移。
- 驗收：有戰術版對陪練版 ≥ 70%；屬性梯度勝率單調；五狙陣容輸給均衡陣容。
- **實作（步驟 6，`shooter-baseline` 2.0，`bots/shooter-src/` 合成單檔）**：
  - 隊內協調只靠喊話：活著的最小 playerId 當指揮。計畫 `P:`（T：`P:rushA 0`、`P:splitA 0 2[ go]`、`P:default A 0 1[ >B]`、`P:fake B 0 1[ >B]`、`P:go A 0`；CT：`P:hold A=2 M=1 B=2[ rot=B][ go]`）、買法 `B:full／force／half／eco`、事件 `E:contact <區域> <人數>`、`E:dead`、`E:planted`、`E:flash x y tick`、`E:smoke`、`E:kit`。指揮換人重喊；事件依警覺延遲反應。
  - T：五種計畫（依經濟、侵略、兩點成敗與對方是否 eco 抽），分組走地圖算出的路線到待命格，執行時先煙（封最可能的架點）再閃再進；剩 35 秒強行執行；下包後守包點守點位（看 CT 回防入口）；聽到拆包丟燃燒／手雷。
  - CT：A／中路／B 預設 2／1／2（中路＝多條 T 路線經過、CT 先到的交界），狙擊手拿長對線位；對方連打同一點就多放人、甚至疊 4 人；接觸估計某點 ≥ 2 人就輪轉（另一點留錨點），輪轉與回防先到包點外的待命位集結，炸彈下了集結完畢（或時間只夠現在走）才一起進；拿拆彈器的人優先拆、其他人看入口；來不及就保槍；燃燒封 rush 的入口。
  - 道具：照引擎飛法模擬彈道才丟；閃光選「可能有人看得到、隊友看不到」的爆點，丟的人與隊友收到 E:flash 會躲到看不到爆點的格或轉身。
  - 屬性另接：侵略（rush 比例、default 執行時機、殘局找人、保槍）、紀律（服從買法、不追殘血、保槍）、警覺（事件反應延遲）、走位（佈置時靜步）。
