# 軍團戰 美術風格 v1

Oct 23, 2026 · 方向已定案；色碼、尺寸、時間等數值是草案，原型實測後調整 · 規則見 `軍團戰 規格書 v0.1（草案）.md`

一句話定調：**電競轉播一場沙盤兵推。**戰場是擺在桌上的模型沙盤，轉播資訊疊在上面。

## 一、風格方向

### 選定風格：微縮沙盤（Miniature dioramas）

高空鏡頭、圓潤的模型造形、柔和的接觸陰影，讓整個戰場看起來像一座桌上模型。參考遊戲：Tiny Glade、Dorfromantik、Townscaper（風格說明見 game-art-style skill 的 `miniature-diorama`，畫面請到 [原頁](https://gameartstyle.loopyhop.com/styles/miniature-diorama/) 看）。

選這個風格的理由：

1. **視角吻合**：觀戰是上帝視角看全軍，就是「沙盤推演」。AI 選手指揮、玩家觀戰的設定，正好是在轉播一場兵推。
2. **可讀性**：這種風格靠大塊色彩構圖，不靠細節。遠看軍團是一塊隊伍色托盤，近看才是一個個模型小兵。
3. **隊伍色有自然的載體**：塗在士兵的底座、盾面和軍團旗上，士兵本身維持中世紀的自然色，戰場不會滿是螢光色。
4. **升級路線順**：Canvas 2D 原型用柔和陰影、圓潤造形、疊板地形就能做出大部分的味道；轉 Unity 時直接改 3D 加接觸陰影與移軸景深。

### 借用的次要風格

- **極簡幾何色塊**：用在遠景層。看全圖時軍團收成托盤色塊加標籤，小地圖也用同一套。

### 明確不做

| 風格 | 原因 |
| --- | --- |
| 像素類 | 鏡頭是 0.15～3 倍連續縮放，像素圖非整數倍會糊或閃爍；看全圖時士兵只有 5～8px，像素小兵只剩幾個色點。像素風（例如用 pxl skill）可以考慮用在經營端，另外討論 |
| 霓虹向量／全像戰術螢幕 | 和 UI 最一致，但沒有中世紀感（第一輪已否決） |
| 電影寫實、厚塗類 | 製作成本高，拉遠會糊成一片 |
| 沙盤桌框 | 第二輪決定不做；地圖外維持深色背景 |

### 鏡頭

- **原型（Canvas 2D）**：正俯視。陣型、朝向、側擊與背擊的角度判讀最準確。模型感靠三件事營造：固定的左上光源與右下投影、直立的旗幟、高地疊板露出南側側面。
- **Unity 階段**：改成小角度斜俯視（俯角約 55～70°，正交或小 FOV 透視，待定），自動導播的近景鏡頭可以再斜一點。

## 二、可讀性原則

1. **辨識優先順序**：隊伍 ＞ 軍團（陣型輪廓與朝向）＞ 兵種 ＞ 狀態（架陣、衝鋒、隱蔽、潰散、老兵）＞ 個別士兵 ＞ 裝飾。
2. **明度層級**：地形低飽和、中明度（飽和度 ≤ 32%、明度 35～60%）；隊伍色高飽和（≥ 70%）。地形永遠比士兵安靜。
3. **最小顯示尺寸**：以「步兵底座在螢幕上的直徑」決定細節等級（見第四節）。看全圖時（縮放約 0.7）底座約 5px，這時必須分得出隊伍、陣型輪廓、朝向；兵種靠軍團標籤的圖示。
4. **不只靠顏色**：重要區分都要有第二重線索。
   - 隊伍：旗幟外形（主隊燕尾旗、客隊方旗）
   - 兵種：底座形狀與武器剪影
   - 狀態：標籤上的圖示與文字
5. **世界與資訊分層**：世界層照沙盤的規則（有光影、有投影）；資訊層照 UI 的規則（固定螢幕大小、不受光影與模糊影響）。

| 金 | `#eab308` | `#713f12` | 紫 |

**配色規則**（每場開戰前決定一次）：

1. 主隊（賽程上的主隊，預設布陣在左方）用主色。
2. 客隊主色和主隊主色比對：在一般視覺與三種色盲模擬（紅色盲、綠色盲、藍色盲）下，任一情況的 ΔE2000 低於門檻（草案 20），客隊就改用客場色。
3. 客場色仍然撞色，客隊改用轉播後備色：藍、橙之中與主隊差異較大的那個。
4. 地圖底色也納入比對。例如之後的雪原圖，銀白隊要自動換色。
5. **色盲模式**（觀眾設定）：不論隊伍，一律主隊藍 `#3b82f6`、客隊橙 `#f97316`。

**隊伍色用在哪裡**：

| 位置 | 顏色 |
| --- | --- |
| 士兵底座 | 主色填色、暗色鑲邊 |
| 盾面（盾兵、劍士小盾） | 暗色 |
| 軍團旗 | 主色旗面、暗色描邊；主隊燕尾、客隊方旗 |
| 托盤 | 主色，填色透明度 .16、邊框 .6 |
| 標籤、計分條、小地圖 | 主色 |
| 士兵身體、馬匹、武器 | 不用隊伍色（自然色） |

### 功能色（只出現在資訊層的深色底板內）

| 顏色 | 色碼 | 用途 |
| --- | --- | --- |
| 青 | `#22d3ee` | 只給 UI 狀態：選取、鏡頭、教學提示。不當隊伍色、不做世界特效 |
| 金 | `#fbbf24` | 老兵、衝鋒、側擊、撞擊數字 |
| 紅 | `#f87171` | 背擊、潰散 |
| 淡灰 | `#cbd5e1` | 隱蔽 |
| 白 | `#e2e8f0` | 架陣、一般狀態 |

金與紅也是隊伍色，所以功能色一定要放在深色底板內、搭配圖示與文字，不能單獨塗在世界上。

### 禁用

- 地形不用飽和綠、飽和紅、青。
- 投影與暗部不用純黑。
- 血跡不用鮮紅（見第四節）。

## 四、物件呈現規格

### 細節等級（LOD）

以步兵底座在螢幕上的直徑 `b` 切換（底座的世界尺寸依引擎的士兵間距決定，草案約 0.45 格）：

| 等級 | 條件 | 畫什麼 |
| --- | --- | --- |
| 遠景 | `b` < 4px | 只畫托盤色塊（填色透明度提高到 .55）＋正面邊加亮＋軍團標籤；不畫個別士兵 |
| 中景 | 4 ≤ `b` < 10px | 底座（形狀＋隊伍色）＋頭部圓點＋武器剪影線＋投影 |
| 近景 | `b` ≥ 10px | 中景全部，再加：底座倒角高光、人物兩階明暗、武器金屬色、盾面、馬匹細節、實體軍團旗 |

### 兵種

辨識方式：**底座形狀＋武器剪影＋軍團標籤圖示**。底座形狀沿用桌上兵棋的慣例。

| 兵種 | 底座 | 中景剪影 | 近景細節 | 隊形特徵 |
| --- | --- | --- | --- | --- |
| 長槍方陣 | 方底 | 長槍伸出前方（長度 ≥ 底座 1.5 倍），槍尖金屬色 | 頭盔、槍尖反光 | 最密、縱深 4～6 排；架陣時槍放平，正面形成刺牆 |
| 劍士 | 方底 | 短劍斜線 | 劍刃金屬光、小圓盾（暗隊伍色） | 中等密度 |
| 盾兵 | 方底 | 前方長條大盾（暗隊伍色） | 盾面徽記 | 前排盾牌連成一道盾牆線 |
| 弓兵 | 圓底 | 弓的弧線 | 箭袋 | 較鬆、偏橫寬 |
| 輕步兵 | 小圓底（0.8 倍） | 投槍短斜線 | 輕裝、無頭盔 | 散開，間距 1.5 倍並隨機抖動 |
| 輕騎兵 | 長方底 | 棕色細長馬身、騎手、短矛 | 鬃毛、皮甲 | 間距大 |
| 重騎兵 | 長方底（1.15 倍） | 鐵灰色披甲馬、長騎槍 | 馬鎧、羽飾 | 緊密橫列 |

人物配色（所有兵種共用）：布與皮 `#e4ddcc`、描邊 `#4a4234`、木柄 `#5b4630`、金屬 `#d4d8dd`、棕馬 `#7a5536`、披甲馬 `#8b9097`。

### 軍團（托盤、旗幟、標籤）

- **托盤**：陣型外框的圓角矩形（圓角 4px），主色填色 .16、邊框 .6、1.3px。正面那條邊加粗到 2px，用來表示朝向；架陣時正面邊改成 2.6px 實色。
- **實體旗**（近景）：旗手站在陣型後排中央。旗桿約 14px 高，旗面為主色、暗色描邊；主隊燕尾、客隊方旗。旗桿往右下投一條影子。
- **軍團標籤**（所有距離，固定螢幕大小）：
  - 深色底板 `rgba(9,13,21,.9)`、邊框 0.8px `rgba(148,163,184,.4)`、高 18px、圓角 4px
  - 左側 3px 隊伍色條、兵種線條圖示（12px）、人數（11px 等寬數字）、狀態標籤
  - 位置在托盤上方，用 6px 引線連到托盤；標籤互相重疊時往上錯開
- **狀態標籤**：架陣（白）、衝鋒（金）、隱蔽（淡灰＋閉眼圖示）、潰散（紅＋白旗圖示）、老兵 Lv2／Lv3（金，一個或兩個 V 形）。
- **需要新增的線條圖示**（沿用 `icons.ts` 的 24×24 線條規格）：長槍、劍、盾、弓、輕步兵、輕騎、重騎、架陣、衝鋒、隱蔽（閉眼）、潰散（白旗）、老兵（V 形）。

### 陣亡

- **倒地模型**：士兵陣亡時用 0.3 秒傾倒，之後留在原地成為倒地模型。
  - 底座橫倒成橢圓，隊伍色混 50% 灰；人物躺倒，掉落的武器畫成一條線
  - 透明度 .75
- **血跡**：每名陣亡士兵 2～4 塊不規則小污漬，大小約底座的 0.6～1.2 倍。騎兵撞擊點的血跡較大。
  - 顏色用暗褐紅 `#4a1c17`、透明度 .35～.55、霧面不反光。明度遠低於紅隊主色，不會和紅隊混淆
  - 畫在倒地模型底下
- **戰場痕跡層**：倒地模型和血跡畫進一張只增不減的離屏 canvas（和地形快取一樣），每幀沒有額外成本。一場打完，地上就留著整場戰鬥的痕跡。
- **血跡開關**：觀眾設定裡提供開關，預設值待確認（見第九節）。

### 潰散

- 托盤消失，隊伍色和暖灰 `#8a8178` 混合 55%。
- 隊形打散：每名士兵隨機偏移，朝向往撤退方向 ±45°，身後畫速度線。
- 軍團旗傾倒約 45°，旗面變灰。
- 標籤換成白旗圖示加「潰散」。
- 士兵走到己方後方的地圖邊緣，最後 2 格淡出。潰兵離場不留痕跡。

### 地形

地形資料是格子，但畫的時候要把輪廓平滑化：用 marching squares 取輪廓，再用 Chaikin 演算法磨圓。鋸齒格線會破壞沙盤感。整張地形只在開局時烘焙一次。

| 地形 | 呈現 |
| --- | --- |
| 平地 | 植絨草底色＋噪點＋低頻色斑 |
| 道路 | 沙土帶加路邊深色描邊、兩條淡輪轍；曲線平滑 |
| 樹林 | 深色地面加苔蘚球樹冠（半徑 0.5～0.9 格，兩階明暗＋高光＋右下投影），依 y 座標排序繪製。樹冠畫在士兵之上 |
| 隱蔽中的軍團 | 所在範圍的樹冠透明度降到 .5，讓觀眾看得到；托盤改成虛線（4,3）；標籤加「隱蔽」 |
| 高地 | 疊板：頂面比平地亮約 8～10%，南側露出 6～10px 側面帶（土層色加細橫紋），右下投影（模糊 6、位移 4,5），邊緣 1.2px 高光。規格只有一階高度 |
| 淺灘 | 淡藍綠水面、卵石點綴、柔和邊界 |
| 河流 | 兩階河岸加樹脂水面；光澤虛線以每秒約 6px 緩慢流動 |
| 橋 | 木板加板縫線、兩側欄杆、投影；寬 2～3 格要一眼看出是隘口 |
| 建築 | 圓角量體；頂視看屋脊線加兩色坡面；投影比一般物件長，暗示會擋視線 |
| 城牆 | 厚度至少 1 格，頂面畫垛口（凹凸交錯），轉角放圓形塔樓，南側露出側面 |
| 旗點（佔點） | 圓形石台加旗桿模型；地面的範圍圈與佔領進度弧用資訊層的畫法（沿用搶點原型） |
| 布陣區 | 開戰前畫半透明隊伍色區塊加斜線，開戰後淡出 |
| 地圖邊緣 | 不做桌框；地圖外 `#0b0d10`，地圖邊加 1px 暗邊和向外的柔和陰影，讓地圖像一塊略微浮起的沙盤板 |

| 密林 | 深綠 `#6d7a4f` | 樹林大面積、狹窄林道 |
| 峽谷 | 赭土 `#9a8463` | 多層疊板岩壁、隘口 |
| 城市 | 石板 `#8b8a82` | 建築群、街道、廣場 |
| 郊外 | 麥田拼布 `#a99a62` | 補丁狀田地、籬笆、農舍 |

## 五、特效清單

原則：**世界層克制、資訊層電競化。**塵土、木屑、火花、血跡這類實體特效維持沙盤的尺度；側擊、背擊、撞擊數字、架陣、隱蔽等資訊用深色底板加圖示標出。只有大撞擊才加輕微鏡頭震動。

| 特效 | 觸發時機 | 世界層 | 資訊層 | 時間 | 優先級 |
| --- | --- | --- | --- | --- | --- |
| 箭雨 | 弓兵齊射 | 每 2～3 名弓兵畫 1 支箭，沿拋物線飛行；箭的影子沿兩點直線在地面移動（表現高度）；落點小塵土；射中盾兵時箭插在盾上 | 選取或近景時顯示淡虛線彈道 | 飛行 0.8～1.5 秒 | P0 |
| 衝鋒 | 騎兵達到衝鋒速度 | 身後米色塵土尾跡（透明度 ≤ .3）、速度線 | 標籤加「衝鋒」 | 衝鋒期間 | P0 |

## 六、UI 與世界的關係

- **世界層（沙盤）**：地形、模型、實體特效（箭、塵土、火花、血跡）。有光影、有投影，之後的移軸景深也只作用在這一層。
- **資訊層（電競轉播 UI 語言）**：軍團標籤、狀態膠囊、傷害數字、隱蔽標示、佔點範圍圈、選取框。
  - 統一用深色底板、細邊框、11px 字、等寬數字、線條圖示（線寬 1.8～2.4）
  - 固定螢幕大小，不投影、不模糊
- **計分條、數據面板、解說欄**：沿用 `web/style.css` 的電競轉播風，不改。
- **小地圖**：地形簡化色加托盤色塊（和遠景 LOD 同一套），隱蔽軍團用虛線框，交戰熱點沿用現有畫法。
- **青色**只屬於 UI，不出現在世界層。

## 七、製作方式

### 原型（Canvas 2D）

全部程式繪製，不用外部素材。

- **繪製順序**：
  1. 地形快取（開局烘焙一次）
  2. 戰場痕跡層（倒地模型、血跡，只增不減）
  3. 投影層
  4. 士兵（依 y 座標排序）
  5. 樹冠
  6. 世界特效（箭、塵土、火花）
  7. 資訊層（標籤、膠囊、範圍圈）
- **士兵**：開局時依當場兩隊的顏色，用程式預先畫好 sprite atlas（7 兵種 × 2 隊 × 16 個朝向 × 中景與近景），之後每幀只做 `drawImage`。不要每幀畫 path，數百名士兵撐不住。
- **投影**：上百名士兵的投影直接疊會越疊越黑。先畫在白底離屏層上，用 `darken` 合成（重疊處取較暗者），最後整層用 `multiply` 疊回主畫面。
- **光源**：固定左上，所有投影往右下。
- **示意圖**：本次討論中的沙盤示意圖（藍橙兩軍、箭雨、架陣、側擊、隱蔽、潰散）就是用 Canvas 2D 即時繪製，以上色碼與尺寸都來自那份小樣，可以當實作起點。

### Unity 階段

- URP。地形用疊板 mesh 加植絨質感 shader。
- 士兵用 GPU instancing（隊伍色走 instanced property），動畫用 vertex animation texture，遠景切換成托盤 impostor。
- 接觸陰影用 decal 或貼地 quad；建築開 SSAO。
- 移軸景深只套在畫面上下約 10% 的帶狀區、只用在近景鏡頭，不能糊到交戰區；資訊層不受影響。

### AI 產圖（ComfyUI，之後）

- **可以用**：地形材質（植絨草、土層、卵石）、建築屋頂、地圖選擇畫面的插畫、戰隊徽章。
- **不用**：士兵與特效，一律程式繪製，因為要套隊伍色、分多級細節。
- **提示詞**：以 game-art-style skill 的 `miniature-diorama` 提示詞為基礎。不寫遊戲名，不拿參考遊戲的截圖當參考圖。

### 像素素材

- 軍團戰不用像素風。
- pxl skill（已安裝）可以考慮用在經營端：選手頭像、戰隊徽章、設施場景、事件插圖。另外討論。
