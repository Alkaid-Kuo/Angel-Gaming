# CS 射擊 Bot 2.3：局部局勢判斷與守包生存

日期：2026-11-02。分支：`codex/bot-2-3`。本階段依使用者實玩與觀戰回饋實作；尚未提交或推送。

## 使用者回饋與實作

1. **隊友剛交火陣亡，Bot 無戒備地撿 C4。** 拾取人選改看實際通路距離、近期開火與低血量的機會成本；正在壓制的人可以讓另一名空閒隊友接手。死亡事件會撤銷附近過時的安全標記，保留較久的局部風險，接近時先架可能的危險角度。死亡點不當成敵人的精確位置。
2. **普通轉角直走出去，受傷後才回應。** 新增 `judgment.js`：從地圖算出的守位、掩體與一般牆邊候選點，評估即將打開的視線；先轉向，必要時短暫停步，對準或逾時後繼續。這條基本戒備獨立於計畫的 `allowPeek`，因此 rush／執行階段也有預瞄。安全路段不增加固定等待。
3. **換位思考對手會蹲哪裡、走哪裡。** 共用地圖的守位與 T 候選路線作先驗，配合最後接敵、最近死亡與時間可達性排序局部角度。敵人消失後，沿合法通路擴展到可能到達的交界。推測只影響看向與接近方式，開火仍只針對觀察中真正可見的敵人。
4. **T 炸彈即將引爆仍不撤。** 2.2 的守位一直在炸彈附近，沒有撤離邏輯。2.3 計算到保守安全圈的實際路程與武器移速，先讓其他人撤，最後守包者提前靠向仍可看住炸彈的出口側站位。對方無法新開拆時撤離；若看見／聽見拆包，保留拆包警報，避免聲音剛消失就丟下正在拆的人。撤離時解除開鏡，普通架槍、換血等待與追殘血不攔住撤離移動。
5. **守包不使用道具。** 有剩餘煙時，守包前段或接敵後封 CT 回防入口，離炸彈超過 5 格；不自動用包煙遮住拆包者。下包後透過 `E:smoker` 交換實際剩餘煙資訊，再分配彼此分開的入口，不偷讀隊友庫存，也避免同時準備投擲到同一點。燃燒針對已知接近的入口，同時指定一名錨點／支援保留反拆燃燒。既有反拆燃燒／手雷保留，新增 `E:burn x y until` 分享已投擲的燃燒區，避免重複投在同處；煙仍遵守同回合 6 格間距。

## 邊界與工程

- 保留四層架構，新增局部判斷模組，沒有改引擎、選手 API、地圖、反應延遲或六項屬性公式。
- 沒有寫死地圖座標、區域代號或地圖 id。只用 init、公開規則與觀察資料；推測不是透視，也不求解整棵戰術博弈樹。
- API 沒有公布炸彈傷害半徑，Bot 沿用既有的 `P.saveDist` 22 格作保守安全距離，沒有從引擎內部讀取爆炸參數。情境驗收可用公開引擎狀態驗證實際存活。
- 煙與矮掩體後方不再直接標記為已清空（矮掩體採保守判斷）；敵人全滅時清除舊危險成本。
- 建置產物移除程式縮排，保留換行、JSDoc 型別與多行字串原始內容；使用 Acorn 詞法範圍保護 template。原始碼維持可讀。產物 184,214 bytes，低於 200 KiB 限制。SHA256：`12bb9be651a2c673874f99318e92c0a1b50941d2fc1e929ba9cfb5a83bcf13d9`。

## 新情境的改前／改後

各情境兩張圖、各五個種子，使用真正編譯後 Bot、反應延遲佇列與引擎投擲／爆炸。

| 情境 | 2.2 | 2.3 |
| --- | --- | --- |
| T20 守包倒數撤離 | 0／10；引爆時兩張圖分別約 10.6／13.5 格，全部陣亡 | 10／10；前段不離守，引爆時約 22.2 格，全部存活 |
| T21 守包煙封入口 | 0／10；沒有投擲 | 10／10；各一顆煙，距炸彈赤岩舊城約 11.2～11.3 格、沙城 14.0 格 |
| T22 燃燒限制回防 | 0／10；沒有投擲 | 10／10；各一顆燃燒，支援保留反拆燃燒 |

另新增 `test/shooter-judgment.test.ts`：開火者與拾取分工、同區域普通轉角、預瞄結束後繼續、煙後安全標記、近期死亡戒備、入口煙、重複道具、拆包警報、撤離，以及建置多行字串保真。

### T17 判定修正

T17 現在檢查「觀察到敵人全滅後不再產生 throw 指令」。先前只數之後出現的投擲物，會把敵人死亡前已經送入反應延遲佇列的指令算成違規。新增決策命令觀測回呼，分開記錄新指令與已排隊道具；沒有改引擎的延遲或取消規則。仍驗證守包前段不追、不新丟、不開槍。

## 實戰對照

`node scripts/shooter-eval.ts --a bots/shooter-baseline.js --b out/bot23/baseline22.js --map redrock --games 20 --lineup 3 --no-limits --jobs 4 --json out/bot23/eval-v3-final40.json`

赤岩舊城、MR6、均衡 v3，20 個種子互換側、共 40 場、486 回合，最終產物 2.3 對 2.2（兩份選手快照保留在 `out/bot23/`）：

- 整場 22 勝 18 敗（55.0%），回合 257／486（52.9%）。當 T 158／243（65.0%）、當 CT 99／243（40.7%）。這個樣本只能支持沒有明顯崩壞，不能證明穩定變強。
- 兩邊例外 0、逾時 0。`--no-limits` 關閉牆鐘限制；決策平均 0.150 ms、最大 48.17 ms，init 最大 38.3 ms（同機有情境測試在執行，最大值包含排程影響）。
- 2.3 閃光隊友／敵方致盲 12.2%，下包率 80.7%，回防成功率 30.3%。
- 此處 T 回合占比來自新舊 Bot 混打，**不拿來當 2.3 鏡像平衡驗收**，也不替代 200 個獨立種子的 T 勝率窗口量測。

## 後續量測範圍

這次新增的是局部幾何與情報判斷；各回合仍會有不確定的敵方位置，也沒有進行全局戰術搜尋。實玩回饋應繼續補成情境，觀察它有沒有恢復任務、是否變得過度保守。

`SHOOTER_POWER` 與 k 尚沿用 2.2.1；這份表不能當成已對 2.3 重量過的結果。2.2.1 的 T 勝率 56.8% 也不直接沿用為 2.3 的平衡結論。
