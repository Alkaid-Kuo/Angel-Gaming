# UI 審核巡檢（M5 後第一次完整實玩回饋）

2026-11-07 · 分支 `claude/ui-audit-m5-6de3c9` · 基準 main c029c60（攻防戰 1.2、Bot 2.8、M5 教練層四批、存檔第 11 版）

目標：經營層正式版（`web/game.html`）與攻防戰教練頁（`web/shooter.html#coach`）整個巡一輪，修到「像一個遊戲該有的樣子」：看不到調試用按鈕、沒有跑版、每個區塊一眼看得懂、比賽回放只在檔案室。

## 一、怎麼巡的

- 無頭 Chromium（playwright-core）開工作樹的 vite（`.claude/launch.json` 的 `ui-audit`，埠 5216，用 `vite.worktree.config.ts` 讓工作樹的檔案也被監看），每個畫面 1920×1080 與 1366×768 各截一張，同時跑小字（實際顯示 < 10 px）與溢出視窗的稽核。截圖在 `docs/shots/ui-audit-m5/`（`before-`／`after-` 前綴）。
- 經營層用展示模式 `?demo=7&content=shooter-1&weeks=N&still`（不碰 localStorage）：休賽期、例行賽第 4 週、比賽日三選一與五幕、教練模式、一般觀戰、決賽與頒獎、破產。
- 另外在瀏覽器窗格實際操作：戰隊頁點位與拖曳、選手詳情的訓練按鈕、教練模式的滑鼠反應。
- 嚴重度：**高**＝看不清、被切掉、按不到或明顯錯誤；**中**＝影響理解或操作但繞得過去；**低**＝觀感、一致性。

## 二之一、PR 1 做了什麼（去網頁感、小修、跑版）

- **去網頁感**（#3 更正後的意思）：`web/game.css`、`web/shooter.css` 全站 `user-select: none`（輸入框、種子欄、下拉保留）、`img`／`svg` 不可拖且不吃滑鼠、游標只有 default 與 pointer、`:focus` 外框拿掉改 `:focus-visible` 金框、捲軸統一 6px 細版、數字輸入框的上下箭頭拿掉、右鍵選單關掉（`main.ts`，輸入框保留）。
- **自製提示**：全部 `title` 換成 `data-tip`（純 CSS，滑過 0.35 秒浮出，墨底金邊；面板右緣的用 `tip-r` 靠右，才不會被面板切角裁掉）。
- **開發入口**：標題畫面與選單拿掉「舊版介面」（`club.html` 檔案保留，網址仍可開）；標題底部的「M4 PROTOTYPE …數值都還在調整」改成「ANGEL GAMING · 攻防戰 1.2 · SEASON 01」。
- **#1 選手翻頁**：選手詳情左上「← 上一位」「下一位 →」（帶頭像與名字），鍵盤 ← → 也能切；順序＝自己人照戰隊頁陣容順序、自由球員照市場列表、別隊照該隊名單評分，循環。
- **#11、#14 屬性列**（`src/web/game/attrs.ts`）：每列「屬性名 · 數值 · 等級 · 下一點 xx% 進度條 · 已排 n 節 ≈ ＋x.x · 練 1 節 ＋0.6」；預估由 `trainGain(級中值, 目前)` 算、規則沒動；預估為 0 才標「已達上限」（同一級內還有幾點可練時不算）。停用時按鈕本身寫原因：已達上限、已排 3 節、時段用完、資金不足、賽段結束，滑過有完整說明。面板放得下 7 列（原本最後一列被切）。
- **#10 財務單位**：每週固定收支、本賽段累計、帳本三個清單的數字後面加「萬」；固定收支列高縮到 24px，7 人時淨額不再貼底。
- **#19 數據板**：切換鈕改「數據 STATS ↔ 名單 LINEUP」；每列加頭像。
- **跑版**：基地右側「聯賽」標籤的桿加長（60→150），不再被「對手總部」蓋住；賭盤休賽期改成一張說明卡；市場底部提示縮成一行；雷達圖軸名 13→15px。
- 工具：`vite.worktree.config.ts`＋`.claude/launch.json` 的 `ui-audit`（埠 5216），工作樹裡改檔畫面會更新（主設定排除了 `.claude/worktrees`；不能用 `mergeConfig`，陣列會合併而不是取代）。

## 二之二、PR 2 做了什麼（版面重排、檔案室、教練 HUD）

- **#8 演出與回放**：比賽日演出每一幕的「跳過演出／加速」控制列整條拿掉（演出速度留在選單，一幕一幕點畫面或空白鍵就過）；結果幕與聯賽賽程的「觀戰」拿掉。新畫面**檔案室**（側欄第 10 項，側欄鈕縮到 74px 高）：已打完的比賽列表（週次、主客隊、比分、勝負、我方該場最常打的戰術前三）＋「全部比賽」分頁；回放走既有的 `watch` 路徑。別隊之間的比賽只有比分與名單（已知層本來就沒有他們的戰術），沒有任何隱藏層欄位。
- **#2 卡對卡拖曳**：出賽卡本身 `draggable`，拖到另一個出賽位就互換（沿用 `setLineup`）；拖動時所有出賽位亮成虛線放置區，被拖的卡變淡；右邊陣容列拖到卡上照舊。
- **#3 五張卡**：等高排一列（不再 2、4 號位下沉）、卡放大到 0.68、卡頂只剩「階段 · 品階徽章 · 英文階級」，強度等級「C-／C-／B-」移到卡下資訊列（流派 · 等級）；市場大卡同一套卡頂。
- **#16 訓練基地**：01 設施（等級與升級＋兩條額度：練習賽場數、訓練時段，各註明用在哪、連去哪排）／02 排練習賽（對手、場數、排入）／03 本週排程（練習賽、屬性訓練、戰術排練、球探分組，每組有「去排」）／04 報告。**戰術室**：兩張表等分高度（防守方最後一列不再被切）、表頭欄名滑過有說明、排練鈕寫節數與停用原因；右欄拆成 03 排練（節數）／04 比賽計畫（經濟風格、助理教練）／05 對手情報。
- **#6 教練模式 HUD**（`src/web/shooter/`，只用 Worker 現在送的教練 frame：view、self、board）：
  - 原因：Worker 以 `spectate: false` 跑教練模式，前端用玩家模式 HUD（準星跟滑鼠、鏡頭隨滑鼠偏、$、血甲彈藥、武器欄都是被跟隨那個 Bot 的，且全部 `pointer-events: none`），沒有觀戰用的選手列表、控制列、滑鼠鏡頭。
  - 改法：教練模式也建 `SpectateUi`，選手資料由 `coachPlayers()` 從教練 frame 拼：己方＝所看隊友（`view.me`）與其他隊友（`view.teammates`）的血量、金錢、武器、炸彈、下包／拆包；對手＝計分板的存活、擊殺、死亡，位置不給（點不到）。只能跟隨己方（`followOnly`），Worker 的 `view` 訊息在教練模式接受己方的 id。輸入與渲染當觀戰用（不瞄準、不開火、無準星、鏡頭不跟滑鼠偏），`teamFog` 不變、透視永遠關、沒有下一回合與倒帶。控制列：速度、跟隨／自由／全圖鏡頭、全螢幕、按鍵表、離席回經營；教練列只剩回合、暫停、轉一般觀戰，移到回合橫幅下方不再互壓；下方中央血甲彈藥、左下 $、右下武器欄不顯示（和一般觀戰一樣）。隊友列只顯示知道的欄位（彈藥與護甲只有所看那位有）。回合橫幅在教練模式寫「我方 CT」而不是「你是 CT」。

- **#15 戰術說明**：戰術室每個戰術名滑過顯示內容包的 desc 與 tips（名字右側半透明小面板，字小，不塞進列表）；教練票多帶 tips（只供顯示），教練暫停面板選戰術的按鈕滑過顯示同一份相剋提示。
