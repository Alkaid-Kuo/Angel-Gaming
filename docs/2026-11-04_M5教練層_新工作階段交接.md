# M5 教練層：新工作階段交接

日期：2026-11-04。寫給接手 M5 規格的新工作階段。基底：main `6467386`（M4 經營層、攻防戰引擎 1.2、基準 Bot 2.5 第三批、品階與立繪第二版、新手教學逐週開放、試玩只留基準 v1～v5）。

## 一、為什麼有 M5

使用者 2026-11-04 實玩後的判斷：看 Bot 打架好玩，經營體驗偏差。根因是經營層把模擬器參數直接端給玩家：訓練只回一個加成數字、升版只是版本號加一、比賽只回比分、選手只有版本線。討論後決定不做呈現層修補，而是把選手與戰術系統重做，並加一層「教練」讓玩家在比賽中有事可做。

## 二、已定方向（使用者口頭同意，細節待規格）

1. **選手改屬性制**：六項屬性直接存在選手身上，開局用現有 `derivePlayer` 公式生成，之後靠訓練累積。版本改成由屬性推導的「成長階段」稱號，只作顯示與評分起點，不再是可購買的東西；升版指令與費用拿掉。
2. **稀有度改成屬性上限**：上限 ＝ 角色基準 ＋ 稀有度餘裕，不是固定數。訓練收益隨接近上限遞減。
3. **訓練改成針對單一屬性**：先只開放瞄準、反應、警覺三項強度屬性；侵略、紀律、走位三項風格屬性先鎖（教練系統以後再說）。訓練中心等級決定每週次數，成為主要支出。
4. **戰術研發退場，改成隊伍層戰術手冊**：具體戰術（T：Rush A、Rush B、Default、Split、Fake；CT：2-1-2、疊 A、疊 B、激進探點）各有熟練度，訓練基地排練才漲；熟練度影響 Bot 抽選權重與執行品質（經旋鈕）。「針對流派」研發刪除。
5. **比賽個人統計回饋**：閘道回傳每人擊殺、死亡、首殺、存活、下拆包、殘局勝；結果幕、選手近況、賽季累計都用它。
6. **教練層與即時比賽**：只有我方比賽即時算，回合凍結時間可喊暫停換戰術、CT 分點、經濟策略；暫停次數有限；NPC 教練也會喊；不看的比賽照賽前設定自動解決；教練指令記進回放。
7. **公開／隱藏界線不變**：`knownView()` 仍是唯一入口。習慣仍隱藏；球探仍有價值。

## 三、使用者尚未拍板（規格要列成問題請他回文字）

- 成長階段命名（草案：新秀／正選／主力／明星／傳奇）。
- 屬性上限要不要加隱藏潛力帶（公開顯示稀有度給的區間，實際上限由習慣決定）。
- 戰術手冊是純隊伍制，還是加個人「拿手戰術」。
- 戰術清單用草案九個，或增減。
- 賽前戰術傾向設定要不要與熟練度同批。
- 暫停次數：每半場一次，或整場兩次任意。
- 對手隊選手的個人統計是否公開（草案：公開）。

## 四、依賴順序（規格分批時照這個）

戰術手冊與 Bot 旋鈕 → 選手屬性制與訓練 → 比賽個人統計 → 即時比賽與暫停。每批獨立可驗收。Bot 側要開的旋鈕（戰術權重、執行品質係數、每回合重讀旋鈕）屬 Bot 2.7，由 Bot 工作階段做，規格要寫清楚接口。
