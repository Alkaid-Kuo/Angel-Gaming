# M4 完整 UI 設計稿

2026-10-27 · 待你看過。分支 `sketch/m4-full-ui`（疊在 `sketch/m4-ui-styles` 上，未合併）。

用定案的 E＋A 統一規格，把 M4 經營層的全部畫面畫成 1920×1080 的設計稿，共 15 張，加上 A 的基地首頁一共 16 個畫面。所有畫面用同一組假資料：第 4 週、本週對手暗影工作室、現金 104.8 萬、第 7 名。各畫面的數字前後對得起來，例如財務頁的帳本、週結算的現金滾動、積分榜名次。

## 一、怎麼看

`npm run web` 後開 <http://localhost:5173/web/sketch/ui/>，是全部畫面的總覽頁，依流程分四組。點縮圖進去看動態。

- 畫面之間能點：左側導覽列、左下的「比賽日」、結果頁的「週結算」、週結算的「進入第 5 週」等按鈕都有連結。
- 基地（A，`web/sketch/cyber.html`）是首頁：點建築上的 AR 標籤、我方名單、對手情報、開戰鈕、信件、隊徽，會進到對應畫面。
- 網址加 `?still` 是截圖模式，會略過進場動畫。
- 直接開 HTML 檔看不到內容，一定要開發伺服器。

## 三、規格與元件

色票、字型、頂列、斜切標籤沿用 `web/sketch/angel.css`，見[風格草圖文件](2026-10-27_經營介面風格草圖.md)的「〇、定案」。這次新增的元件在 `web/sketch/ui/ui.css`：

| 元件 | 用法 |
| --- | --- |
| 背景 `.bgx` | 墨黑放射漸層、透視地板（格線＋金環＋轉動的虛線環）、描邊大字、光束、暗角；各頁換大字（SQUAD、MARKET…） |
| 左側導覽 `.rail` | 8 個入口＋金色圓形「比賽日」；目前頁左邊一條斜金邊；紅色數字徽章＝未讀，金點＝有新東西 |
| 頁首 `.ph` | 金色英文小標＋斜體大字中文＋一行說明 |
| 面板 `.pn` | 深色漸層加細斜紋、左緣粗邊、右下切角；`.g` 金＝我方或選中、`.r` 紅＝對手 |
| 按鈕 `.btn` | 平行四邊形；金＝主要行動（一個畫面原則上只有一顆）、`.ghost` 白框＝次要、`.danger` 紅框＝解約這類危險動作 |
| 選手卡 `.pc` | 收藏卡；版本只用明暗與金的多寡區分：v1 灰框、v2 白框、v3 金框、v4 白框加金內線、v5 雙金框加光暈、v6 金框加流光 |
| 頭像 | 我方灰階後染金；對手與他隊染灰（`.av.foe`、`.tinted.grey`） |
| 其他 | 晶片 `.chip`、分頁 `.tabs`、量條 `.meter`、分段 `.segs`、表格列 `.row`（`.me` 金、`.foe` 紅、`.cut` 季後賽虛線）、勝負章 `.stamp` |

`src/web/sketch/ui.ts` 負責共用外框：各頁在 `#stage` 標 `data-screen` 與 `data-word`，它就放上背景、頂列、導覽列。演出畫面標 `data-shell="none"`，只放背景，不放頂列與導覽。它也幫隊徽、頭像、流派徽記補上統一的顏色，再交給 `fill.ts` 畫。

## 四、我替你先決定的事

你出門前說「交給你」，以下是我照統一規格自己下的判斷，都可以改：

| 事項 | 我的做法 | 原因 |
| --- | --- | --- |
| 他隊隊徽 | 一律墨黑底、灰白圖騰；本週對手用紅 | 原本每隊有自己的顏色（黃、藍、紫、青…），會破壞「只有金和紅」的原則 |
| 流派徽記 | 保留原本 8 種圖形，但全部單色 | 原本 8 個流派各有一色，同上 |
| 版本稀有度 | 不用青銅、紫鑽石這類顏色，改用框的明暗與金的多寡 | 同上；名稱（青銅、白銀、黃金…）照舊 |
| 自創隊徽的配色 | 只給白金、墨金、金墨、墨白、灰金、白墨 6 組 | 介面主色固定是金；隊徽如果能選紅綠藍，會跟介面打架 |
| 基地要不要放左側導覽 | 不放，基地靠 AR 標籤導覽 | 導覽列會蓋到我方名單與城市；其他畫面都有導覽列可回基地 |
| 對手頭像 | 染灰、紅框 | 金只留給我方，一眼分得出敵我 |
| 金色按鈕 | 原則上一個畫面只有一顆 | 讓「下一步該按哪裡」永遠清楚 |
| 下注的錢 | 下注時先扣本金，押中時發還本金＋獎金 | 跟核心的記帳方式一致（`commands.ts` 下注扣款、`betting.ts` 開獎入帳） |

## 五、限制與沒做的

- 這是設計稿：除了連結，按鈕都不會真的改資料；拖曳排陣、下注金額晶片等互動沒有做。正式介面要接 `src/manage` 的 `knownView()` 與指令。
- 只做桌面 1920×1080（等比縮放）。手機版需要另外排版：導覽列改到底部、三欄改成上下堆疊。
- 已驗證：16 個畫面在開發伺服器實跑沒有主控台錯誤，基地與市場頁約每秒 144 格；型別檢查與 lint 通過；每張都用 Edge 無頭模式截圖檢查過版面。
- 沒驗證：Safari、Firefox，以及 Google 字型離線時的退回字型。
