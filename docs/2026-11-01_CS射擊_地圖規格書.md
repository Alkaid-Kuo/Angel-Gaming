# 攻防戰 地圖規格書（v1，2026-11-01）

> 目的：之後 6～9 張地圖都照這一份做，每張圖只討論它不同的地方。下面的實測值都是赤岩舊城定案版（`maps/shooter/redrock.json`，引擎 1.2.0，規則 1.2 包量測）。

## 一、地圖池與用途

| 用途 | 說明 |
| --- | --- |
| 正式地圖 | 進聯賽地圖池，經營層賽季會打；每張都要過第五節全部門檻。目前一張：赤岩舊城 |
| 試玩地圖 | 試玩頁可選、賽季不用；過門檻前的新圖都放這裡 |
| 測試地圖 | 沙城：只給引擎測試與 Bot 驗收，玩家看不到 |

地圖池封板前，強度表只在首張正式地圖量一次；封板時再量一次全池。封板後加圖＝再量一次，所以一批一批封。

聯賽選圖規則（待定，地圖池 ≥ 2 張時才需要）：每輪固定輪替／種子隨機／主場圖。

## 三、路程與節奏（軟條件，對照赤岩舊城定案版）

| 項目 | 赤岩舊城（實測） | 允許範圍（暫） |
| --- | --- | --- |
| T 到 A／B 中心 | 30.9／27.5 秒 | 25～33 秒 |
| CT 到 A／B 中心 | 12.2／11.5 秒（差 0.7 秒） | 10～14 秒；兩點差 ≤ 3 秒 |
| A 到 B 中心（回防） | 23.6 秒 | 20～25 秒 |
| 矮掩體格數 | 120 格（20 組） | 60～130，且只在交戰點 |
| 首次接觸 | 19.2 秒（基準 v3 對 v3、200 場，開打起算） | 17～22 秒 |

路程量法：出生點 3 號到包點中心最近的可走格，地圖編輯器的路徑場（8 方向、斜走算 √2），AK／M4 跑速 215 units／秒（4.10 格／秒）。檢查面板的「到包點」是到包點框最近一格，所以較短（T 29.6／25.5、CT 9.7／9.8 秒）。

## 四、設計原則（使用者定）

1. 不做死巷房間，所有空間都要連通成路線。
2. 掩體只放交戰點（包點、門口、路口），不鋪滿地。
3. 不用 Bot 使用率判斷房間價值，看結構。
4. 借結構不借關卡：參考現成地圖的路線邏輯，格局原創。
5. 視野公平：地圖資料不得讓任一方出生就看到對方。

## 六、檔案格式（`maps/shooter/<代號>.json`）

- `MapLayout`：`id`、`name`、`width`、`height`、`theme?`、`decor?`、`areas[]`（`id`、`name`、`x0..y1`、`material?`、`callout?`）、`blocks[]`、`polys[]`（`slope`）、`low[]`、`sites[]`、`spawnZones`、`spawns`。
- `theme?`：材質族代號，預設 `redrock`。`decor?`：擺設（格座標，只給畫面）：`wells`（矩形，要壓在牆方塊上）、`tarps`（矩形，鋪在 `market` 材質的空地，壓到障礙就不畫）、`sitePaint`（包點塗裝圓環的 `id`、`x`、`y`、`r`，沒寫就自動找位置）。
- `material`：`stone`、`dirt`、`wood`、`market`、`plaza`、`site`；併入的框（`callout`）沒標就跟主區域。地圖編輯器存檔會保留 `theme`、`decor`。
- 代號：英文小寫與連字號，定稿後不改（寫進存檔）；定稿前的版本用 `-v2`、`-door` 這種字尾，定稿時去掉。
- 名稱：中文，玩家看到的。

## 七、風格接口（預留）

- 一張圖一個 `theme`；一個 theme＝`src/web/shooter/themes/` 一個檔，實作 `theme.ts` 的 `MapTheme`：調色盤、六類地面材質畫法、屋頂、矮掩體道具組、牆邊道具、擺設圖樣；再到 `themes/index.ts` 登錄一行。
- 引擎與 Bot 不知道 theme；`MapInfo` 不帶它，畫面依地圖代號查（`mapVisualOf`）。
- 新風格的流程：先出一張 1920×1080 樣張（照這次三方向樣張的做法）→ 使用者拍板 → 寫 theme 檔 → 地圖 JSON 指定。
- 每張圖的主題與調性：**個別討論時定**（佔位：9 張）。

## 八、製作流程（每張圖）

1. 一頁骨架：路線圖手繪或方格草圖、兩點位置、長線、主題一句話。
2. 編輯器畫（`web/shooter-map-editor.html`），存 `maps/shooter/<代號>-v1.json`。
3. 檢查器全過，全圖 SVG。
4. Bot 200 場看平衡；陪練 40 場。
5. 依數字調（門寬、掩體、長線），每版一筆 commit 與一張對照表。
6. 使用者實打。
7. 區域名定案、材質與擺設標齊。
8. 去掉版本字尾，在 `map.ts` 的 `LAYOUTS` 登錄、試玩頁下拉加一項，成為試玩地圖。
9. 達門檻後進地圖池（一批一批封板，封板時重跑強度表）。
